# break

가장 가까운 반복문 또는 switch를 즉시 종료합니다.

## 개념과 동작 원리

break는 가장 가까운 반복문 또는 switch를 종료하고 그 문장 뒤로 이동합니다. 현재 함수 전체를 종료하는 return과는 다릅니다.

## 사용 시점과 다른 개념의 구분

검색 성공·잘못된 상태·사용자 종료 선택처럼 반복을 즉시 끝낼 때 사용합니다. 중첩 전체 종료에는 별도의 흐름 설계가 필요합니다.

## 문법과 예제

```cpp
for (int i = 0; i < 5; ++i) {
    if (i == 3) break;
    std::cout << i << ' ';
}
```

**결과:** 0 1 2. 중첩 반복문 전체가 아니라 가장 안쪽 반복문만 종료합니다.

## 예제를 이해하는 순서

i가 3이면 출력문에 도달하기 전에 반복을 빠져나옵니다. 그래서 3 이후의 값도 출력되지 않습니다.

## 이해 확인

**질문:** switch가 반복문 안에 있으면 break는 어디를 끝내는가?

**답:** 가장 가까운 switch만 끝냅니다. 바깥 반복문은 계속될 수 있습니다.
