# while: 조건이 참인 동안

본문을 실행하기 전에 조건을 검사합니다. 처음부터 거짓이면 한 번도 실행하지 않습니다.

## 개념과 동작 원리

조건을 먼저 검사하고 참인 동안 본문을 반복합니다. 종료를 위해 상태가 어떻게 바뀌는지 본문이나 외부 입력에서 확인해야 합니다.

## 사용 시점과 다른 개념의 구분

입력 종료·게임 종료·찾을 때까지 반복처럼 횟수를 미리 모를 때 사용합니다. 처음 조건이 거짓이면 한 번도 실행하지 않습니다.

## 문법과 예제

```cpp
int count = 0;
while (count < 3) {
    std::cout << count << ' ';
    ++count;
}
```

**결과:** 0 1 2. `++count`가 없으면 종료 조건에 가까워지지 않습니다.

## 예제를 이해하는 순서

count를 출력한 뒤 증가하므로 0, 1, 2를 출력합니다. 증가가 빠지면 count < 3이 계속 참으로 남을 수 있습니다.

## 이해 확인

**질문:** 조건에 쓰는 변수는 꼭 본문에서 바꾸는가?

**답:** 입력·함수 결과 등으로도 바뀔 수 있습니다. 핵심은 종료 조건에 도달할 경로가 있는지입니다.
