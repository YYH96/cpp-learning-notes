# 추상 클래스와 순수 가상 함수

순수 가상 함수 = 0은 파생 타입이 제공할 계약입니다. 미구현 순수 가상 함수가 남은 클래스는 직접 객체로 만들 수 없습니다.

## 개념과 동작 원리

순수 가상 함수는 파생 타입이 구현할 계약을 표현합니다. 최종 재정의되지 않은 순수 가상 함수가 남으면 클래스는 직접 인스턴스화할 수 없습니다.

## 사용 시점과 다른 개념의 구분

씬·전투 행동처럼 공통 역할은 있지만 기본 동작 하나로 표현하기 어려운 경우에 사용합니다. 추상 클래스에도 데이터나 일반 함수 구현을 둘 수 있습니다.

## 문법과 예제

```cpp
class Scene { // main 밖
public:
    virtual ~Scene() = default;
    virtual void Update() = 0;
};
```

**예:** Scene scene;은 불가. 구체 파생 클래스가 Update를 구현해야 합니다.

## 예제를 이해하는 순서

Scene의 Update는 = 0으로 계약만 지정합니다. 파생 씬이 필요한 함수를 재정의하면 구체 객체로 만들 수 있습니다.

## 이해 확인

**질문:** 추상 클래스 포인터나 참조도 만들 수 없는가?

**답:** 만들 수 있습니다. 직접 객체 생성이 불가한 것이며 파생 객체를 가리키는 공통 인터페이스로 사용합니다.
