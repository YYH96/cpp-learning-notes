# 소멸자

객체 수명이 끝날 때 정리 작업을 수행합니다. 클래스 이름 앞에 ~를 붙이고 인자를 받지 않습니다.

## 개념과 동작 원리

소멸자는 객체 수명이 끝날 때 자원 정리를 수행하는 특별한 멤버 함수입니다. 자동 객체는 범위를 벗어나면 소멸자가 실행되어 RAII 정리 구조를 만들 수 있습니다.

## 사용 시점과 다른 개념의 구분

동적 메모리·파일·잠금처럼 획득한 자원을 타입이 책임지고 정리할 때 사용합니다. 단순 멤버를 가진 타입은 직접 소멸자를 작성할 필요가 없을 수 있습니다.

## 문법과 예제

```cpp
class Trace { // main 밖
public:
    ~Trace() { std::cout << "Destroyed"; }
};
```

**예:** { Trace value; } 블록 종료 시 Destroyed 출력. 기반 포인터로 파생 객체를 삭제하는 설계에는 가상 소멸자가 필요합니다.

## 예제를 이해하는 순서

Trace 객체가 블록을 벗어나면 Destroyed를 출력합니다. 객체의 소멸자 본문 이후 멤버와 기반 클래스도 정해진 순서로 소멸합니다.

## 이해 확인

**질문:** 포인터 변수 소멸 시 대상도 삭제되는가?

**답:** raw 포인터에는 그런 자동 소유권 규칙이 없습니다. 소유 객체나 스마트 포인터의 정리가 필요합니다.
