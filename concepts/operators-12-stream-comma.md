# 입출력 연산과 쉼표

같은 기호도 피연산자 타입에 따라 역할이 달라집니다.

| 표현 | 의미 | 예 |
| --- | --- | --- |
| cout << value | 출력 스트림에 값 넣기 | std::cout << hp |
| cin >> value | 입력 스트림에서 값 읽기 | std::cin >> hp |
| integer << n | 정수 비트 왼쪽 이동 | 1u << 3 |
| integer >> n | 정수 비트 오른쪽 이동 | 8u >> 1 |
| (expr1, expr2) | 왼쪽 실행 후 오른쪽 식의 값 사용 | (x += 1, x * 2) |

```cpp
int x = 3;
int value = (x += 1, x * 2);
std::cout << x << ' ' << value;
```

**결과:** 4 8. 함수 호출 Print(a, b)의 쉼표는 인자 구분자이며 쉼표 연산자가 아닙니다.

**주의:** 복잡한 쉼표 식은 문장을 나눕니다. 출력 스트림의 <<와 비트 이동의 <<를 구분합니다.
