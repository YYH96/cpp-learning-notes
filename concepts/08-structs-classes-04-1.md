# enum

이름을 붙인 정수 상수들의 집합입니다. 일반 enum의 열거자는 둘러싼 범위에 들어가고 정수로 암시적 변환할 수 있습니다.

## 개념과 동작 원리

열거형은 관련된 이름 있는 값들의 타입입니다. 일반 enum의 열거자 이름은 둘러싼 범위에 들어가며 정수로 암시적 변환될 수 있습니다.

## 사용 시점과 다른 개념의 구분

방향·상태·메뉴처럼 의미가 정해진 값에 이름을 붙일 때 사용합니다. 임의 숫자보다 역할이 잘 드러나지만 다른 enum 이름과 충돌할 수 있습니다.

## 문법과 예제

```cpp
enum Direction { Left, Right }; // main 밖
```

**예:** Direction d = Right; int value = d;에서 value는 1. 이름 충돌을 줄이려면 enum class를 고려합니다.

## 예제를 이해하는 순서

Left는 별도 값 지정이 없어 0, Right는 다음 값 1입니다. Direction 값을 정수 변수에 저장하면 해당 정수값을 얻습니다.

## 이해 확인

**질문:** 열거형의 크기는 언제나 int와 같은가?

**답:** 고정된 기반 타입을 지정하지 않은 경우 일률적으로 단정하면 안 됩니다. 표현 타입과 값 범위를 확인합니다.
