# 이동과 std::move

std::move는 이동을 허용하는 값 범주로 바꿉니다. 그 자체로 자원을 옮기지 않으며 이후 선택된 이동 연산이 처리합니다.

## 개념과 동작 원리

이동은 자원 소유권 이전 등의 최적화 가능한 갱신 방식을 제공하는 생성·대입 동작입니다. std::move는 값을 이동 후보로 취급하게 만들 뿐 직접 자원을 옮기지 않습니다.

## 사용 시점과 다른 개념의 구분

임시 값·더 이상 현재 내용이 필요하지 않은 자원 소유 객체를 전달할 때 고려합니다. 작은 단순 값은 이동해도 복사와 같은 비용일 수 있습니다.

## 문법과 예제

```cpp
std::string a = "Hero";
std::string b = std::move(a);
std::cout << b;
```

**결과:** Hero. 이동 후 a는 유효하지만 값은 단정하지 않습니다. 이동이 제공되지 않으면 복사가 선택될 수도 있습니다.

## 예제를 이해하는 순서

string b = std::move(a)에서 선택된 생성자가 실제 작업을 수행합니다. 이동 후 a의 내용은 예제에서 단정하지 않고 유효한 상태의 규칙에 맞게 사용합니다.

## 이해 확인

**질문:** const 객체에 move하면 항상 이동하는가?

**답:** 일반적인 이동 생성자는 비const rvalue를 받으므로 const 대상에서는 복사가 선택될 수 있습니다.
