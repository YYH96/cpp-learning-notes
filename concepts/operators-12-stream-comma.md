# 입출력 연산과 쉼표

같은 기호도 피연산자 타입에 따라 역할이 달라집니다.

## 개념과 동작 원리

C++의 연산 기호는 타입과 오버로딩에 따라 의미가 달라질 수 있습니다. 내장 쉼표 연산은 왼쪽 평가 후 오른쪽 평가 결과를 제공합니다.

## 사용 시점과 다른 개념의 구분

<<가 스트림 출력인지 정수 비트 이동인지 피연산자로 판단합니다. 함수 인자를 구분하는 쉼표는 쉼표 연산자가 아닙니다.

## 문법과 예제

| 표현 | 의미 | 예 |
| --- | --- | --- |
| cout << value | 출력 스트림에 값 넣기 | std::cout << hp |
| cin >> value | 입력 스트림에서 값 읽기 | std::cin >> hp |
| integer << n | 정수 비트 왼쪽 이동 | 1u << 3 |
| integer >> n | 정수 비트 오른쪽 이동 | 8u >> 1 |
| (expr1, expr2) | 왼쪽 실행 후 오른쪽 식의 값 사용 | (x += 1, x * 2) |

```cpp
int x = 3;
int value = (x += 1, x * 2);
std::cout << x << ' ' << value;
```

**결과:** 4 8. 함수 호출 Print(a, b)의 쉼표는 인자 구분자이며 쉼표 연산자가 아닙니다.

**주의:** 복잡한 쉼표 식은 문장을 나눕니다. 출력 스트림의 <<와 비트 이동의 <<를 구분합니다.

## 예제를 이해하는 순서

(x += 1, x * 2)는 먼저 x를 4로 변경한 뒤 8을 계산합니다. 마지막 8이 value에 저장되며 x 자체는 4입니다.

## 이해 확인

**질문:** 모든 쉼표가 평가 순서를 보장하는가?

**답:** 아닙니다. 함수 인자 구분자와 내장 쉼표 연산을 같은 것으로 해석하면 안 됩니다.
