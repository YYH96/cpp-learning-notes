# 증가·감소 연산자

++는 1 증가, --는 1 감소입니다. 앞에 붙이면 변경된 값을, 뒤에 붙이면 변경 전 값을 식의 결과로 사용합니다.

## 개념과 동작 원리

전위와 후위 모두 변수를 1 변경합니다. 차이는 식의 결과로 변경 후 값과 변경 전 값 중 무엇을 사용하는지입니다.

## 사용 시점과 다른 개념의 구분

반복 인덱스·개수 갱신에 사용합니다. 결과값을 사용하지 않으면 전위·후위의 최종 값은 같지만, 결과를 다른 변수에 저장하면 차이가 드러납니다.

## 문법과 예제

| 표현 | 식의 값 | 변수 변화 |
| --- | --- | --- |
| ++x | 증가 후 값 | 1 증가 |
| x++ | 증가 전 값 | 1 증가 |
| --x | 감소 후 값 | 1 감소 |
| x-- | 감소 전 값 | 1 감소 |

```cpp
int x = 3;
int before = x++;
int after = ++x;
std::cout << before << ' ' << after << ' ' << x;
```

**결과:** 3 5 5.

**주의:** 독립 문장 x++;와 ++x;는 최종 x가 같습니다. 한 식에서 같은 변수의 증감과 다른 읽기를 복잡하게 섞지 말고 문장을 나눕니다.

## 예제를 이해하는 순서

x가 3일 때 before = x++는 3을 저장하고 x를 4로 바꿉니다. 이어 ++x는 5로 바꾼 뒤 after에 5를 제공합니다.

## 이해 확인

**질문:** 후위는 다음 문장에서야 증가하는가?

**답:** 아닙니다. 해당 식의 평가 중 증가하며, 식의 값으로 이전 값을 제공한다는 뜻입니다.
