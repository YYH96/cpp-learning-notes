# auto: 초기값에서 타입 추론

## 개념과 동작 원리

auto는 초기식으로부터 컴파일 시간에 타입을 결정합니다. 실행 중 마음대로 타입이 바뀌는 동적 타입 변수가 아닙니다.

## 사용 시점과 다른 개념의 구분

복잡한 반복자 타입·표현식 결과를 간결하게 선언할 때 사용합니다. 값 복사와 참조 유지 여부는 auto와 auto& 등 선언 방식으로 지정합니다.

## 문법과 예제

```cpp
int hp = 100;
auto copy = hp;
auto& alias = hp;
alias = 80;
```

**결과:** hp와 alias는 80, copy는 100. auto가 항상 참조를 유지하는 것은 아닙니다. 읽기 전용 참조는 const auto&로 지정합니다.

## 예제를 이해하는 순서

copy는 hp 값을 가진 독립 int이고 alias는 hp의 참조입니다. alias = 80은 원본을 바꾸지만 copy에는 처음 값 100이 유지됩니다.

## 이해 확인

**질문:** auto a = 참조변수는 항상 참조인가?

**답:** 일반 auto 값 선언은 참조를 그대로 유지하지 않습니다. 참조가 필요하면 auto& 등을 명시합니다.
