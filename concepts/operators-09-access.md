# 멤버·인덱스·호출·범위 연산자

객체의 멤버, 배열의 원소, 함수, 이름 공간의 이름에 접근합니다.

## 개념과 동작 원리

접근 연산은 복합 데이터 안에서 필요한 대상을 고릅니다. .는 객체의 멤버, ->는 포인터 대상의 멤버, []는 원소, ::는 이름의 소속을 지정합니다.

## 사용 시점과 다른 개념의 구분

플레이어 상태·배열 칸·클래스의 공유 값·이름 공간에 접근할 때 사용합니다. 객체 선택과 이름 범위 선택을 혼동하지 않습니다.

## 문법과 예제

| 기호 | 용도 | 예 |
| --- | --- | --- |
| . | 객체의 멤버 | hero.hp |
| -> | 포인터가 가리키는 객체의 멤버 | p->hp, (*p).hp |
| [] | 인덱스 접근 | values[0] |
| () | 함수 호출 | Print(), 함수 인자 전달 |
| :: | 이름 공간·클래스 범위 지정 | std::cout, Player::count |

```cpp
struct Player { int hp; };
Player hero{100};
Player* p = &hero;
int values[2]{10, 20};
p->hp -= values[0];
std::cout << hero.hp << ' ' << values[1];
```

**결과:** 90 20.

**주의:** 배열과 vector의 []는 일반적으로 범위를 자동 검사하지 않습니다. 유효 인덱스인지 확인합니다. 포인터의 ->도 유효한 객체를 가리킬 때만 사용합니다.

## 예제를 이해하는 순서

p->hp는 (*p).hp와 같은 멤버를 가리킵니다. values[1]은 두 번째 원소이며, std::cout은 std 이름 공간의 이름입니다.

## 이해 확인

**질문:** []가 잘못된 인덱스를 항상 막는가?

**답:** 일반 배열이나 vector의 []에는 범위 검사 보장이 없으므로 직접 유효 범위를 확인합니다.
