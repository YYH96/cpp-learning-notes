# 동적 할당과 소유권

## 개념과 동작 원리

동적 객체는 생성한 지역 포인터의 블록이 끝나도 자동으로 소멸하지 않습니다. 소유권은 누가 자원을 정리할 책임이 있는지 나타내는 설계 규칙입니다.

## 사용 시점과 다른 개념의 구분

실행 중 정해지는 수명·크기에 필요할 수 있지만 vector·string·unique_ptr 같은 RAII 도구를 우선 고려합니다. 관찰 포인터와 소유자를 구분합니다.

## 문법과 예제

```cpp
int* one = new int(10);
int* many = new int[3]{1, 2, 3};
delete one;
delete[] many;
```

**핵심:** new와 delete, new[]와 delete[]를 짝 맞춥니다. 포인터 변수가 사라져도 동적 객체는 자동 삭제되지 않습니다.

**주의:** 삭제한 주소를 다시 사용하거나 두 번 삭제하면 안 됩니다. 소유자는 자원 해제를 책임지는 주체입니다.

## 예제를 이해하는 순서

one은 단일 객체여서 delete, many는 배열이어서 delete[]로 해제합니다. 포인터를 다른 곳에 복사해도 해제 책임이 여러 개로 늘어나면 안 됩니다.

## 이해 확인

**질문:** delete 뒤 포인터를 nullptr로 만들면 모두 안전한가?

**답:** 그 포인터만 초기화됩니다. 같은 주소를 보관한 다른 별칭은 여전히 유효하지 않을 수 있습니다.
