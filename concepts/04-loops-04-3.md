# 중첩 반복문

반복문 안에 반복문을 두어 행·열 같은 조합을 처리합니다.

## 개념과 동작 원리

바깥 반복의 한 회차마다 안쪽 반복을 처음부터 실행합니다. 행·열 또는 대상 간 조합처럼 두 축의 작업을 표현합니다.

## 사용 시점과 다른 개념의 구분

보드 출력·2차원 배열 처리·쌍 비교에 사용합니다. 전체 실행량은 각 반복의 범위와 내부 종료 조건에 따라 달라집니다.

## 문법과 예제

```cpp
for (int row = 0; row < 2; ++row) {
    for (int col = 0; col < 3; ++col) std::cout << row << col << ' ';
}
```

**결과:** 00 01 02 10 11 12. 두 반복 횟수가 N, M이면 본문은 N*M번 실행됩니다.

## 예제를 이해하는 순서

row 0에서 col 0, 1, 2를 모두 처리하고 row 1에서도 같은 col 순회를 반복합니다. 예제는 총 2 곱하기 3회의 작업입니다.

## 이해 확인

**질문:** 안쪽 반복에서 break하면 바깥도 끝나는가?

**답:** 아닙니다. 안쪽만 끝나고 바깥의 다음 회차가 진행될 수 있습니다.
