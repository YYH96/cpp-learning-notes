# static 지역 변수

이름은 함수의 블록에 속하지만 값은 호출 사이에도 유지됩니다.

## 개념과 동작 원리

이름의 사용 범위는 지역 블록이지만 저장 기간은 일반 지역 변수보다 깁니다. 초기화 지점에 도달하면 초기화하고 이후 호출에서 같은 객체를 사용합니다.

## 사용 시점과 다른 개념의 구분

호출 횟수·함수 내부 공유 상태에 사용합니다. 상태가 호출 사이에 남으므로 테스트·동시 접근·초기화 조건을 함께 고려합니다.

## 문법과 예제

```cpp
int NextId() { // main 밖
    static int count = 0;
    return ++count;
}
```

**결과:** 연속 호출하면 1, 2, 3. 일반 지역 변수처럼 호출마다 0으로 재설정되지 않습니다.

## 예제를 이해하는 순서

count를 호출마다 새로 만들지 않아 반환값이 1, 2, 3으로 증가합니다. 일반 지역 count = 0으로 바꾸면 매 호출 결과가 다시 1이 됩니다.

## 이해 확인

**질문:** 초기화가 안전하면 이후 증가도 동시성 안전한가?

**답:** 아닙니다. 초기화 보장과 여러 스레드가 공유 값을 변경하는 안전성은 별개입니다.
