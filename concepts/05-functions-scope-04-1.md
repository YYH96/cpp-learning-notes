# 스코프

이름을 사용할 수 있는 범위입니다. 일반 지역 변수는 선언 이후 해당 블록 안에서 사용합니다.

## 개념과 동작 원리

스코프는 이름을 사용할 수 있는 영역입니다. 객체가 살아 있는 기간인 수명과 구분하며, 안쪽의 같은 이름이 바깥 이름을 가릴 수 있습니다.

## 사용 시점과 다른 개념의 구분

변수가 필요한 범위 가까이에 선언해 상태 변경과 의존을 줄입니다. 다른 함수의 지역 변수 이름을 직접 사용하는 것은 불가능합니다.

## 문법과 예제

```cpp
int hp = 100;
{ int damage = 20; hp -= damage; }
std::cout << hp;
```

**결과:** 80. damage는 블록 밖에서 사용할 수 없습니다. 같은 이름으로 바깥 변수를 가리면 혼동하기 쉽습니다.

## 예제를 이해하는 순서

damage는 안쪽 블록에서만 이름을 사용할 수 있습니다. hp는 바깥 블록에 있으므로 안쪽에서 변경한 값이 이후 출력에 반영됩니다.

## 이해 확인

**질문:** 이름이 안 보이면 객체도 반드시 소멸했는가?

**답:** 아닙니다. static 지역 객체처럼 이름의 범위보다 오래 살아 있는 객체가 있습니다.
