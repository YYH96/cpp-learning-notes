# C 문자열

char 배열에서 널 문자 \0으로 끝나는 문자열입니다. 저장 공간에는 끝 표시까지 포함해야 합니다.

## 개념과 동작 원리

C 문자열은 연속된 char 데이터에서 첫 널 문자까지를 내용으로 해석합니다. 저장 공간의 크기와 널 문자 앞 내용 길이는 다릅니다.

## 사용 시점과 다른 개념의 구분

C API·고정 문자 버퍼와 연결할 때 사용합니다. 저장·복사·연결 과정에서 공간과 끝 표시를 직접 관리해야 하는 점이 string과 다릅니다.

## 문법과 예제

```cpp
char name[] = "Hero";
std::cout << name << ' ' << sizeof(name);
```

**결과:** Hero 5. 문자열 길이는 4, 배열 크기는 끝 표시를 포함해 5바이트입니다. 직접 쓸 때 범위와 널 종료를 지킵니다.

## 예제를 이해하는 순서

Hero 네 문자 뒤에 널 문자가 하나 있어서 배열 크기는 5입니다. 출력은 널 문자에서 멈추며 중간에 널 문자를 넣으면 이후 문자는 출력 내용에서 제외됩니다.

## 이해 확인

**질문:** 널 문자가 없으면 strlen이 길이를 알아낼 수 있는가?

**답:** 유효한 종료 표시 없이 호출하면 범위 밖까지 읽을 수 있어 올바른 문자열이 아닙니다.
