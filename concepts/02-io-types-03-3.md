# getline 줄 입력

std::getline으로 공백을 포함한 한 줄을 읽습니다. <string>과 입력 스트림이 필요합니다.

## 개념과 동작 원리

getline은 구분자까지 문자들을 읽고 구분자는 소비하되 결과 문자열에는 넣지 않습니다. 기본 구분자는 줄바꿈입니다.

## 사용 시점과 다른 개념의 구분

공백이 있는 이름·문장·한 줄 명령에 사용합니다. 단어를 읽는 >>와 한 줄을 읽는 getline의 입력 단위를 구분합니다.

## 문법과 예제

```cpp
std::string name;
std::getline(std::cin, name);
std::cout << name;
```

**예:** Kim Hero 입력 시 Kim Hero 출력. cin >> 다음에 호출하면 남아 있는 줄바꿈 처리부터 확인합니다.

## 예제를 이해하는 순서

Kim Hero를 입력하면 공백을 포함해 저장됩니다. 첫 문자가 줄바꿈이면 빈 문자열을 얻을 수 있으므로 앞 입력이 남긴 문자를 확인합니다.

## 이해 확인

**질문:** 빈 줄은 입력 실패인가?

**답:** 빈 문자열을 읽었다는 사실만으로 실패는 아닙니다. EOF나 오류 여부는 스트림 상태로 판단합니다.
