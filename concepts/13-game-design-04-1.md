# 싱글톤

하나의 인스턴스를 제공하는 패턴입니다. 전역 상태와 의존이 커지므로 필요한 경우에 제한적으로 사용합니다.

## 개념과 동작 원리

외부에 하나의 공유 인스턴스를 제공하고 생성·복사 경로를 제한하는 패턴입니다. 접근이 쉽지만 전역 상태처럼 의존 관계를 숨길 수 있습니다.

## 사용 시점과 다른 개념의 구분

여러 객체가 같은 관리자를 써야 하는 제한된 경우에 검토합니다. 테스트에서 교체가 필요한 서비스는 명시적 전달 방식과 비교합니다.

## 문법과 예제

```cpp
class Manager { // main 밖
    Manager() = default;
public:
    static Manager& Instance() { static Manager value; return value; }
    Manager(const Manager&) = delete;
    Manager& operator=(const Manager&) = delete;
};
```

**예:** Manager::Instance()는 같은 인스턴스를 반환합니다. 인스턴스 생성의 안전성과 그 내부 상태 변경의 동시성 안전성은 별개입니다.

## 예제를 이해하는 순서

Instance 안의 static 객체는 호출마다 새로 생기지 않습니다. 생성자를 private로 두고 복사를 금지해 외부의 별도 인스턴스 생성을 제한합니다.

## 이해 확인

**질문:** 인스턴스가 하나면 모든 작업이 동시성 안전한가?

**답:** 아닙니다. 생성 보장과 인스턴스의 공유 상태를 동시에 변경하는 안전성은 따로 설계합니다.
