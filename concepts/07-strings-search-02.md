# strlen과 sizeof

## 개념과 동작 원리

strlen은 종료 표시를 찾기 위해 문자 데이터를 순회하고, sizeof는 타입이나 객체의 저장 바이트 수를 구합니다. 내용 검사와 저장 형태 검사는 서로 다릅니다.

## 사용 시점과 다른 개념의 구분

C 문자열 내용 길이는 strlen, 실제 배열 저장 공간은 sizeof로 확인합니다. 문자열 포인터가 받는 sizeof는 원래 배열 길이가 아닙니다.

## 문법과 예제

| 표현 | 구하는 것 | "Cat" 배열의 결과 |
| --- | --- | --- |
| strlen(word) | 널 문자 전까지의 문자열 길이 | 3 |
| sizeof(word) | 실제 배열의 저장 바이트 수 | 4 |
| sizeof(pointer) | 포인터 자체의 바이트 수 | 빌드 환경에 따라 다름 |

**주의:** std::string은 char 요소 수를 셉니다. UTF-8 한글의 화면 글자 수와 다를 수 있습니다.

## 예제를 이해하는 순서

Cat의 내용은 3문자이고 널 종료 배열은 4바이트입니다. 같은 배열을 가리키는 포인터의 크기는 내용 길이와 무관합니다.

## 실제 배열과 포인터 비교

```cpp
char word[] = "Cat";
const char* pointer = word;
std::cout << std::strlen(word) << ' ' << sizeof(word) << ' '
          << sizeof(pointer);
```

**결과, MSVC x64:** 3 4 8. `<cstring>`이 필요합니다. 첫 값은 문자열 내용 길이, 두 번째는 널 종료 포함 배열 크기, 세 번째는 포인터 객체 크기입니다.

## 이해 확인

**질문:** 함수 인자 char word[]에 sizeof를 쓰면?

**답:** 매개변수는 포인터 타입으로 조정되므로 원래 배열 전체 크기를 얻지 못합니다.
