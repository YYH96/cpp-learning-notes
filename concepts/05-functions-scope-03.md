# 재귀: 자기 자신 호출

종료 조건과 종료 조건에 가까워지는 변화가 모두 필요합니다.

## 개념과 동작 원리

큰 문제를 같은 형태의 더 작은 문제로 나누고 종료 조건에서 멈춥니다. 호출마다 매개변수·지역 상태와 돌아갈 지점을 가진 실행 맥락이 생깁니다.

## 사용 시점과 다른 개념의 구분

트리 탐색·부분 문제 계산처럼 구조가 재귀적인 경우에 사용합니다. 단순 누적은 반복문이 더 명확하거나 깊은 호출을 피할 수 있습니다.

## 문법과 예제

```cpp
int Sum(int n) { // main 밖, n은 0 이상의 작은 정수
    if (n == 0) return 0;
    return n + Sum(n - 1);
}
```

**결과:** Sum(3)은 3 + 2 + 1 + 0, 즉 6. 호출이 깊어지면 스택 공간도 더 사용합니다.

## 예제를 이해하는 순서

Sum(3)은 Sum(2), Sum(1), Sum(0)을 호출합니다. 0에서 반환을 시작하고 각 호출의 n을 더하며 결과 6을 만들고 돌아옵니다.

## 이해 확인

**질문:** 종료 조건만 있으면 충분한가?

**답:** 아닙니다. 호출 인자가 실제로 종료 조건에 가까워져야 하며 입력 범위와 호출 깊이도 확인해야 합니다.
