## 객체 수명·생성자·소멸자

생성자는 객체를 초기화하고, 소멸자는 객체 수명이 끝날 때 정리합니다.

```cpp
class Player { // main 밖
    int hp;
public:
    explicit Player(int value) : hp(value) {}
    ~Player() = default;
};
```

```cpp
{ // main 안
    Player hero(100);
} // hero의 소멸자 실행
```

**주의:** 초기화 목록에 쓴 순서가 아닌, 클래스에서 멤버를 선언한 순서로 초기화합니다.

## static 지역 변수와 static 멤버

| 구분 | 유지·공유 범위 | 기억할 점 |
| --- | --- | --- |
| 일반 지역 변수 | 현재 블록 실행 | 블록이 끝나면 소멸 |
| static 지역 변수 | 호출 사이에 유지 | 이름은 해당 블록에서만 사용 |
| static 멤버 변수 | 클래스의 객체들이 공유 | 객체마다 별도 저장되지 않음 |
| static 멤버 함수 | 클래스에 속한 함수 | this가 없음 |

```cpp
int NextId() { // main 밖
    static int count = 0;
    return ++count;
}
```

**결과:** 연속 호출하면 1, 2, 3. 호출할 때마다 count가 0으로 돌아가지 않습니다.

## 동적 할당과 소유권

```cpp
int* one = new int(10);
int* many = new int[3]{1, 2, 3};
delete one;
delete[] many;
```

**핵심:** new와 delete, new[]와 delete[]를 짝 맞춥니다. 포인터 변수가 사라져도 동적 객체는 자동 삭제되지 않습니다.

**주의:** 삭제한 주소를 다시 사용하거나 두 번 삭제하면 안 됩니다. 소유자는 자원 해제를 책임지는 주체입니다.

## 복사 생성·복사 대입·이동

| 동작 | 상황 | 예 |
| --- | --- | --- |
| 복사 생성 | 기존 객체로 새 객체 초기화 | Player b = a; |
| 복사 대입 | 이미 존재하는 객체에 대입 | b = a; |
| 이동 | 이동 연산이 선택되면 자원 이전 등을 수행 | Player b = std::move(a); |

**주의:** std::move 자체가 자원을 옮기는 것은 아닙니다. raw 포인터를 소유한 클래스는 기본 복사 시 같은 자원을 공유해 중복 해제가 생길 수 있으므로 복사 정책을 정해야 합니다.
