템플릿, auto와 연산자 오버로딩

한눈에 보는 핵심

템플릿은 타입에 독립적인 코드를 만들고, 연산자 오버로딩은 사용자 타입의 연산 의미를 정합니다.

01

템플릿

타입을 매개변수로 받아 여러 자료형에 같은 구조를 적용합니다.

02

auto

초기화 식에서 타입을 추론합니다. 동적 타입 변수가 아닙니다.

03

연산자 재정의

사용자 타입에 자연스러운 비교·접근·증감 동작을 정의합니다.

개념 비교

표현의미사용 기준
auto value = item;타입 추론, 보통 값 복사독립된 값을 사용할 때
auto& value = item;참조로 바인딩원본을 수정할 때
const auto& value = item;읽기 전용 참조복사를 피하고 읽을 때
자주 헷갈리는 점

연산자 오버로딩은 연산자의 우선순위나 피연산자 개수를 바꾸지 못합니다. 기존 연산 의미에 맞게 설계합니다.

상세 설명과 예제 펼치기필요한 내용만 골라 읽기+

자료형에 공통인 설계

템플릿은 자료형만 달라지고 구조·로직이 같은 함수나 클래스를 하나의 설계로 표현합니다. 실제 사용하는 타입에 따라 컴파일러가 필요한 코드를 인스턴스화합니다. auto는 초기식으로부터 타입을 추론하며 실행 중 타입이 자유롭게 바뀌는 변수를 만드는 기능은 아닙니다. const T&는 불필요한 복사를 줄이고 읽기 목적으로 입력을 받습니다.

함수·클래스 템플릿

cpp
#include <iostream>
#include <string>
template<typename T>
T Add(T left, T right) { return left + right; }
template<typename T>
class Cube {
    T first, second;
public:
    Cube(const T& a, const T& b) : first(a), second(b) {}
    const T& GetFirst() const { return first; }
};
int main() {
    std::cout << Add<int>(10, 20) << '\n'; // 30
    std::cout << Add<double>(1.5, 2.5) << '\n'; // 4
    Cube<std::string> weapons("Sword", "Shield");
    std::cout << weapons.GetFirst() << '\n';
}

좌표 비교 연산자

사용자 정의 타입에도 의미 있는 연산자를 구현할 수 있습니다. 좌표는 x·y가 모두 같을 때 ==가 참입니다. 자료구조에서는 []·*·++ 등도 구현했습니다.

cpp
#include <iostream>
struct Position {
    int x = 0, y = 0;
    bool operator==(const Position& other) const {
        return x == other.x && y == other.y;
    }
    bool operator!=(const Position& other) const { return !(*this == other); }
};
int main() {
    Position snake{3,4}, apple{3,4};
    std::cout << (snake == apple) << '\n'; // 1
}
