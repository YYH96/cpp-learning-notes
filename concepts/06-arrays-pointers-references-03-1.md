# 참조

기존 객체의 별칭입니다. 초기화할 때 대상을 정하며 다른 대상으로 연결을 바꿀 수 없습니다.

## 개념과 동작 원리

참조는 이미 존재하는 객체에 대한 별칭입니다. 초기 바인딩 후 다른 대상으로 재연결되지 않으며 참조를 통한 쓰기는 원본에 반영됩니다.

## 사용 시점과 다른 개념의 구분

항상 유효한 대상이 있어야 하는 인자·반환 접근에 사용합니다. 값 복사와 달리 독립된 데이터를 만드는 것이 아닙니다.

## 문법과 예제

```cpp
int hp = 100;
int& alias = hp;
alias = 70;
std::cout << hp;
```

**결과:** 70. 참조에 대입하면 대상의 값이 바뀝니다. 참조 대상의 수명이 끝나지 않았는지 확인합니다.

## 예제를 이해하는 순서

alias = 70은 별칭의 대상 hp를 변경합니다. 다른 변수를 alias에 대입하더라도 대상 연결이 바뀌는 것이 아니라 그 값이 hp로 복사됩니다.

## 이해 확인

**질문:** 참조가 대상을 자동으로 오래 살게 하는가?

**답:** 일반 객체에 바인딩한 참조는 대상 수명을 자동 연장하지 않습니다. 임시 객체의 수명 연장은 별도 규칙입니다.
