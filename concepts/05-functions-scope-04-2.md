# namespace

이름 공간으로 이름의 소속을 구분합니다. ::로 소속을 지정합니다.

## 개념과 동작 원리

이름 공간은 관련 이름을 묶고 동일 이름의 충돌을 줄이는 영역입니다. 저장 공간이나 객체 인스턴스를 만드는 클래스와는 역할이 다릅니다.

## 사용 시점과 다른 개념의 구분

게임·수학·입출력 등 모듈별 함수·타입·상수를 구분할 때 사용합니다. ::로 어느 이름 공간의 이름인지 명시합니다.

## 문법과 예제

```cpp
namespace Game { constexpr int MaxHp = 100; } // main 밖
```

**사용:** Game::MaxHp는 100. std::cout의 std도 이름 공간입니다. 헤더에서 using namespace std를 광범위하게 쓰지 않습니다.

## 예제를 이해하는 순서

Game::MaxHp는 Game에 속한 상수입니다. std::cout도 표준 라이브러리 이름 공간에 속한 출력 객체를 지정합니다.

## 이해 확인

**질문:** using namespace는 이름을 복사하는가?

**답:** 아닙니다. 이름 탐색에 영향을 줍니다. 헤더에 넓게 적용하면 포함한 코드의 이름 충돌을 늘릴 수 있습니다.
