# cout 출력

<iostream>의 std::cout에 <<로 값을 출력합니다.

## 개념과 동작 원리

cout은 표준 출력 스트림 객체입니다. <<는 값을 스트림에 넣고 같은 스트림을 돌려주므로 여러 출력을 이어 쓸 수 있습니다.

## 사용 시점과 다른 개념의 구분

상태·계산 결과·디버그 메시지를 출력할 때 사용합니다. char는 문자, bool은 기본 설정에서 0 또는 1처럼 타입과 출력 설정에 따라 표현이 달라집니다.

## 문법과 예제

```cpp
int hp = 100;
std::cout << "HP: " << hp << '\n';
```

**결과:** HP: 100. \n은 줄바꿈, std::endl은 줄바꿈과 버퍼 flush를 함께 수행합니다.

## 예제를 이해하는 순서

문자열 HP:를 넣은 뒤 hp 값을 넣고 줄바꿈을 추가합니다. 화면 표시와 버퍼 비우기는 구분하며 endl은 둘 다 수행합니다.

## 이해 확인

**질문:** 줄바꿈마다 endl이 필요한가?

**답:** 보통은 줄바꿈 문자로 충분합니다. 즉시 버퍼를 비워야 할 때 flush 기능을 고려합니다.
