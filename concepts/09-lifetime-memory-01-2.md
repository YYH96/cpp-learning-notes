# 생성자와 초기화 목록

객체 생성 시 멤버를 초기화합니다. 생성자는 클래스와 이름이 같고 반환형을 쓰지 않습니다.

## 개념과 동작 원리

생성자는 객체가 만들어질 때 초기 상태를 설정합니다. 초기화 목록은 멤버를 본문 전에 직접 초기화하며, 본문 안 대입은 이미 초기화된 멤버를 변경하는 동작입니다.

## 사용 시점과 다른 개념의 구분

필수 데이터·참조·const 멤버를 유효한 상태로 구성할 때 사용합니다. explicit은 허용하지 않을 암시적 변환을 제한합니다.

## 문법과 예제

```cpp
class Player { // main 밖
    int hp;
public:
    explicit Player(int value) : hp(value) {}
    int GetHp() const { return hp; }
};
```

**예:** Player hero(100); 뒤 hero.GetHp()는 100. 멤버는 초기화 목록의 표기 순서가 아니라 선언 순서로 초기화됩니다.

## 예제를 이해하는 순서

Player(100)의 value로 hp를 직접 초기화합니다. 멤버 초기화 순서는 목록에 쓴 순서가 아니라 클래스에 멤버를 선언한 순서입니다.

## 이해 확인

**질문:** const 멤버에 생성자 본문에서 대입하면 되는가?

**답:** 변경할 수 없으므로 초기화 목록이나 멤버 초기값으로 처음부터 구성해야 합니다.
