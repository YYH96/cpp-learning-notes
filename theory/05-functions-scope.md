## 함수의 기본 문법과 호출

함수는 **반환형, 이름, 매개변수, 본문**으로 구성합니다. `return`은 결과를 돌려주고 현재 함수 호출을 끝냅니다.

```cpp
int Add(int a, int b) { // 함수 정의: main 밖
    return a + b;
}
```

```cpp
int result = Add(2, 3); // 함수 호출: main 안
```

**결과:** result는 5. 호출한 곳으로 결과가 돌아옵니다. 반환값이 없는 함수의 반환형은 `void`입니다.

| 이름 | 의미 | 위 예제 |
| --- | --- | --- |
| 반환형 | 결과의 타입 | int |
| 매개변수 | 함수가 입력을 받는 변수 | a, b |
| 인자 | 호출할 때 전달하는 값 | 2, 3 |

## 오버로딩과 기본 인자

- **오버로딩:** 같은 이름, 다른 매개변수 목록. 반환형만 달라서는 구분할 수 없습니다.
- **기본 인자:** 호출에서 생략한 인자에 사용할 값. 생략할 수 있는 매개변수는 뒤쪽에 둡니다.

```cpp
int Scale(int value, int factor = 2) { // main 밖
    return value * factor;
}
```

**결과:** Scale(3)은 6, Scale(3, 4)는 12.

## 재귀: 자기 자신 호출

종료 조건과 종료 조건에 가까워지는 변화가 모두 필요합니다.

```cpp
int Sum(int n) { // main 밖, n은 0 이상의 작은 정수
    if (n == 0) return 0;
    return n + Sum(n - 1);
}
```

**결과:** Sum(3)은 3 + 2 + 1 + 0, 즉 6. 호출이 깊어지면 스택 공간도 더 사용합니다.

## 스코프·수명·namespace

| 개념 | 뜻 | 핵심 |
| --- | --- | --- |
| 스코프 | 이름을 사용할 수 있는 범위 | 중괄호 밖에서 지역 이름 사용 불가 |
| 수명 | 객체가 존재하는 기간 | 일반 지역 객체는 블록 종료 때 소멸 |
| namespace | 이름의 소속 | std::cout의 std가 이름 공간 |

**주의:** 스코프와 수명은 같은 뜻이 아닙니다. static 지역 변수는 호출이 끝나도 값을 유지합니다.
