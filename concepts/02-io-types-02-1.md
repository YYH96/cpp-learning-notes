# 변수와 초기화

변수는 타입과 이름을 가진 저장 공간입니다. 사용할 값으로 초기화합니다.

## 개념과 동작 원리

초기화는 객체를 처음 만들며 값을 정하는 동작이고, 대입은 이미 존재하는 객체의 값을 바꾸는 동작입니다. 이름은 저장 공간에 접근하기 위한 식별자입니다.

## 사용 시점과 다른 개념의 구분

체력·점수처럼 실행 중 달라지는 상태에 변수를 사용합니다. 선언할 때 유효한 초기값을 주어 사용 전 상태가 분명해지도록 합니다.

## 문법과 예제

```cpp
int hp{100};
double speed{2.5};
hp -= 20;
std::cout << hp;
```

**결과:** 80. 초기화하지 않은 일반 지역 int를 읽지 않습니다. 중괄호 초기화는 축소 변환을 제한합니다.

## 예제를 이해하는 순서

int hp{100};은 생성과 초기화입니다. hp -= 20;은 기존 객체를 갱신합니다. 중괄호 초기화는 허용하지 않는 축소 변환을 검사합니다.

## 이해 확인

**질문:** 초기화하지 않은 지역 int는 자동으로 0인가?

**답:** 일반적인 자동 지역 int는 그렇지 않습니다. 값을 설정하기 전에 읽으면 안 됩니다.
