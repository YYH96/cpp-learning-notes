# continue

현재 회차의 남은 본문을 건너뛰고 다음 회차로 진행합니다.

## 개념과 동작 원리

현재 반복 회차의 남은 본문을 건너뜁니다. for는 증감식으로, while와 do-while은 다음 조건 검사로 진행합니다.

## 사용 시점과 다른 개념의 구분

조건에 맞지 않는 데이터만 건너뛰고 순회를 이어갈 때 사용합니다. 반복 자체를 끝내는 break와 구분합니다.

## 문법과 예제

```cpp
for (int i = 0; i < 5; ++i) {
    if (i == 2) continue;
    std::cout << i << ' ';
}
```

**결과:** 0 1 3 4. for에서는 증감식을 거칩니다. while에서는 조건 갱신을 건너뛰어 무한 반복하지 않도록 확인합니다.

## 예제를 이해하는 순서

i가 2일 때 출력만 생략하고 다음 i로 진행합니다. while에서 갱신 문장을 continue 뒤에 두면 갱신을 놓칠 수 있습니다.

## 이해 확인

**질문:** continue 뒤의 본문이 실행되는가?

**답:** 해당 회차에서는 실행되지 않습니다. 반드시 수행할 갱신·정리 위치를 확인해야 합니다.
