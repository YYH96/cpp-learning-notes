# for: 횟수와 인덱스

초기식은 한 번 실행합니다. 그다음 **조건 검사, 본문, 증감식**을 반복합니다.

## 개념과 동작 원리

초기식은 한 번, 조건은 매 회차 시작 전에, 증감식은 본문 뒤에 실행됩니다. 반복 변수의 범위를 for 문장 안으로 제한할 수 있습니다.

## 사용 시점과 다른 개념의 구분

횟수·인덱스·컨테이너 원소처럼 진행 규칙이 분명한 순회에 사용합니다. 조건만 중심인 while과 비교하면 초기·증감 규칙을 함께 읽기 쉽습니다.

## 문법과 예제

```cpp
for (int i = 0; i < 3; ++i) {
    std::cout << i << ' ';
}
```

**결과:** 0 1 2. i가 3이 되면 조건이 거짓이므로 종료합니다.

## 예제를 이해하는 순서

i는 0에서 시작해 0, 1, 2일 때 본문을 실행합니다. 증가 후 3이 되면 조건이 거짓이어서 끝납니다.

## 이해 확인

**질문:** i <= 3으로 바꾸면?

**답:** 본문이 한 번 늘어납니다. 크기 3인 배열의 인덱스라면 마지막 3은 범위를 벗어납니다.
