# cin 입력

<iostream>의 std::cin에서 >>로 값을 읽습니다. 문자열은 기본적으로 공백에서 끊깁니다.

## 개념과 동작 원리

>>는 입력을 목표 타입의 값으로 해석합니다. 기본적으로 앞 공백을 건너뛰고, 문자열 입력은 다음 공백 전까지 읽습니다.

## 사용 시점과 다른 개념의 구분

숫자·단어 단위 입력에 사용합니다. 사용자가 올바른 형식을 입력했다는 가정 대신 스트림 성공 여부를 검사합니다.

## 문법과 예제

```cpp
int score = 0;
if (std::cin >> score) std::cout << score;
else std::cout << "Invalid input";
```

**예:** 20 입력 시 20 출력. 숫자 변환 실패 시 스트림 상태를 확인하고 복구해야 합니다.

## 예제를 이해하는 순서

if (cin >> score)는 입력 후 스트림 상태를 확인합니다. 문자 입력을 숫자로 변환하지 못하면 실패 상태를 복구하기 전 다음 추출도 실패할 수 있습니다.

## 이해 확인

**질문:** 실패 후 다시 입력받으려면?

**답:** clear로 실패 상태를 해제하고 잘못된 입력을 ignore 등으로 처리한 뒤 재시도합니다.
