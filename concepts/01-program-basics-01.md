# 프로그램의 기본 구조

`main`은 콘솔 프로그램의 시작점입니다. 문장 끝에는 `;`, 코드 묶음에는 `{ }`를 씁니다.

## 개념과 동작 원리

프로그램은 문장을 실행해 상태를 바꾸고 결과를 출력합니다. main의 본문은 위에서 아래로 진행하되 함수 호출·분기·반복에 따라 흐름이 달라집니다.

## 사용 시점과 다른 개념의 구분

헤더는 필요한 선언을 제공하고, main은 콘솔 프로그램의 시작 함수를 정의합니다. return 0은 운영체제에 정상 종료 상태를 전달합니다.

## 문법과 예제

```cpp
#include <iostream>
int main() {
    std::cout << "Hello\n";
    return 0;
}
```

**결과:** Hello 출력. `#include`는 필요한 선언을 가져오고, `return 0`은 정상 종료 상태를 나타냅니다.

## 예제를 이해하는 순서

Hello 예제는 iostream 선언을 가져온 뒤 출력 문장을 실행합니다. 중괄호는 실행할 문장들의 범위, 세미콜론은 문장의 끝을 표시합니다.

## 이해 확인

**질문:** include와 함수 호출은 같은가?

**답:** include는 전처리 단계의 소스 포함이고, 함수 호출은 실행 흐름을 이동하는 동작입니다.
