# 주소·역참조 연산자

단항 &는 주소를 구하고, 단항 *는 그 주소가 가리키는 객체에 접근합니다.

## 개념과 동작 원리

주소 연산은 객체의 위치를 포인터 값으로 얻고, 역참조는 그 위치에 있는 객체를 가리키는 식을 만듭니다. 주소와 객체의 실제 값은 구분합니다.

## 사용 시점과 다른 개념의 구분

다른 함수·객체가 기존 데이터를 읽거나 변경하도록 연결할 때 사용합니다. 포인터 값의 대입과 포인터가 가리키는 값의 대입은 다릅니다.

## 문법과 예제

```cpp
int hp = 100;
int* p = &hp;
*p = 80;
std::cout << hp << ' ' << *p;
```

**결과:** 80 80. p로 hp를 수정했습니다.

**기호 구분:** a & b는 비트 AND, &a는 주소. a * b는 곱셈, *p는 역참조입니다. int* p의 *와 int& ref의 &는 선언에서 타입을 나타냅니다.

**주의:** nullptr, 해제된 주소, 수명이 끝난 객체의 주소는 역참조하면 안 됩니다.

## 예제를 이해하는 순서

p = &hp는 연결 대상을 정합니다. *p = 80은 주소를 바꾸지 않고 그 주소의 hp 객체를 수정합니다.

## 이해 확인

**질문:** *p가 값을 복사해 만드는가?

**답:** 이 예제에서 *p는 원본 객체를 가리키므로 대입하면 원본이 바뀝니다.
