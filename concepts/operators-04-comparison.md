# 비교 연산자

두 값을 비교해 bool 결과를 만듭니다.

## 개념과 동작 원리

내장 비교 연산은 두 피연산자의 관계를 bool로 표현합니다. 비교 전에 타입 변환이 일어날 수 있으므로 서로 다른 부호·타입의 값을 주의합니다.

## 사용 시점과 다른 개념의 구분

통과 여부·범위 검사·동일성 판단에 사용합니다. 조건을 만족했는지 확인하는 비교와 값을 저장하는 대입을 구분합니다.

## 문법과 예제

| 기호 | 의미 | 예 |
| --- | --- | --- |
| == | 같음 | 3 == 3은 true |
| != | 다름 | 3 != 4는 true |
| <, > | 작음·큼 | 3 < 4는 true |
| <=, >= | 작거나 같음·크거나 같음 | 3 >= 3은 true |

```cpp
int score = 80;
bool pass = score >= 60;
bool inRange = 0 <= score && score <= 100;
std::cout << std::boolalpha << pass << ' ' << inRange;
```

**결과:** true true.

**주의:** 0 <= score <= 100은 수학의 범위 비교처럼 동작하지 않습니다. &&로 두 비교를 연결합니다. 실수는 오차 때문에 정확한 == 비교가 부적합할 수 있습니다. C 문자열의 내용 비교는 포인터의 ==로 하지 않습니다.

## 예제를 이해하는 순서

0 <= score와 score <= 100을 각각 검사해 &&로 묶습니다. 0 <= score <= 100은 앞 비교의 bool 결과를 다시 100과 비교합니다.

## 이해 확인

**질문:** 범위 검사에 비교 하나를 연달아 쓸 수 있는가?

**답:** 수학 표기처럼 쓰지 말고, 두 비교를 논리 연산으로 연결해야 합니다.
