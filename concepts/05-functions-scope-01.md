# 함수의 기본 문법과 호출

함수는 **반환형, 이름, 매개변수, 본문**으로 구성합니다. `return`은 결과를 돌려주고 현재 함수 호출을 끝냅니다.

## 개념과 동작 원리

함수는 입력을 받아 정해진 작업을 수행하는 단위입니다. 호출 시 인자로 매개변수를 초기화하고 본문을 실행한 뒤 호출한 곳으로 돌아옵니다.

## 사용 시점과 다른 개념의 구분

반복되는 계산을 재사용하거나 한 가지 역할을 분리할 때 사용합니다. 함수 이름에는 수행하는 동작이나 반환하는 의미가 드러나도록 합니다.

## 문법과 예제

```cpp
int Add(int a, int b) { // 함수 정의: main 밖
    return a + b;
}
```

```cpp
int result = Add(2, 3); // 함수 호출: main 안
```

**결과:** result는 5. 호출한 곳으로 결과가 돌아옵니다. 반환값이 없는 함수의 반환형은 `void`입니다.

| 이름 | 의미 | 위 예제 |
| --- | --- | --- |
| 반환형 | 결과의 타입 | int |
| 매개변수 | 함수가 입력을 받는 변수 | a, b |
| 인자 | 호출할 때 전달하는 값 | 2, 3 |

## 예제를 이해하는 순서

Add(2, 3)에서 a는 2, b는 3으로 초기화됩니다. return a + b는 5를 반환하고 result가 그 결과로 초기화됩니다.

## 이해 확인

**질문:** 함수 안의 지역 변수 참조를 반환해도 되는가?

**답:** 일반 지역 객체는 함수 종료 때 소멸하므로 그 객체의 포인터·참조를 반환하면 안 됩니다.
