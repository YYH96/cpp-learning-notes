# 배열과 인덱스

배열은 같은 타입의 원소를 연속 저장합니다. 크기가 N이면 인덱스는 **0부터 N - 1**입니다.

## 개념과 동작 원리

배열은 같은 타입의 고정 개수 원소를 연속 저장합니다. 원소 접근은 시작 위치에서 인덱스만큼 원소 크기를 이동한 대상을 지정하는 방식입니다.

## 사용 시점과 다른 개념의 구분

크기가 고정된 점수 목록·좌표·보드에 사용합니다. 실행 중 원소 수를 늘려야 하면 vector 같은 컨테이너를 고려합니다.

## 문법과 예제

```cpp
int scores[3] = {10, 20, 30};
std::cout << scores[0] << ' ' << scores[2];
```

**결과:** 10 30. scores[3]은 범위 밖이며 자동으로 막아주지 않습니다.

## 예제를 이해하는 순서

scores[0]은 첫 원소, scores[2]는 세 번째 원소입니다. 크기 3의 마지막 유효 인덱스는 2이며 3은 경계 다음 위치입니다.

## 이해 확인

**질문:** 배열 이름과 포인터는 같은 타입인가?

**답:** 아닙니다. 배열은 많은 식에서 첫 원소의 포인터로 변환되지만 sizeof 등에서는 배열 자체를 다룹니다.
