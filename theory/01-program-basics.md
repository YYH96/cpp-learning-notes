## 프로그램의 기본 구조

`main`은 콘솔 프로그램의 시작점입니다. 문장 끝에는 `;`, 코드 묶음에는 `{ }`를 씁니다.

```cpp
#include <iostream>
int main() {
    std::cout << "Hello\n";
    return 0;
}
```

**결과:** Hello 출력. `#include`는 필요한 선언을 가져오고, `return 0`은 정상 종료 상태를 나타냅니다.

## 선언과 정의

| 구분 | 하는 일 | 예 |
| --- | --- | --- |
| 선언 | 이름·타입·사용 방법을 알림 | int Add(int a, int b); |
| 정의 | 실제 구현이나 객체를 제공 | int Add(int a, int b) { return a + b; } |
| 호출 | 정의된 동작을 실행 | Add(2, 3); |

**주의:** 함수 선언만 있고 정의가 없으면, 그 함수를 호출하는 프로그램은 링크 오류가 날 수 있습니다.

## 컴파일·링크·디버깅

- **컴파일:** 각 소스의 문법·타입을 확인해 목적 파일을 만듭니다.
- **링크:** 목적 파일과 라이브러리의 정의를 연결합니다.
- **디버깅:** 중단점에서 멈춰 변수 값과 실행 순서를 확인합니다.

**도구 요약:** F9 중단점, F10 함수 내부를 건너뛰며 단계 실행, F11 함수 내부 진입.
