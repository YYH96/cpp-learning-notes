# 게임 루프: 입력·갱신·출력

한 회차마다 입력을 읽고 상태를 바꾼 뒤 현재 상태를 표시합니다. 아래는 흐름을 보여 주는 문법 틀입니다.

## 개념과 동작 원리

게임 상태를 여러 회차에 걸쳐 유지하고, 각 회차에서 사용자 의도 반영·규칙 처리·화면 표현을 진행합니다. 현재 입력과 이전 상태가 다음 상태를 결정합니다.

## 사용 시점과 다른 개념의 구분

스네이크·빙고·TextRPG의 진행을 관리할 때 사용합니다. 턴 기반 입력 대기와 실시간 프레임 갱신은 시간 진행 방식이 다릅니다.

## 문법과 예제

```text
초기화
반복하는 동안:
    입력: 사용자 의도 읽기
    갱신: 이동·충돌·승패 처리
    출력: 현재 상태 표시
자원 정리
```

**주의:** 콘솔의 입력 대기와 실시간 게임의 프레임 갱신은 다릅니다. 프로젝트에 맞춰 입력 처리 방식을 정합니다.

## 예제를 이해하는 순서

입력은 행동 요청, 갱신은 이동·충돌·승패에 따른 상태 변경, 출력은 변경된 상태 표시입니다. 초기화와 자원 정리는 반복 밖의 생명주기로 구분합니다.

## 이해 확인

**질문:** 출력에서 게임 규칙을 바꿔도 되는가?

**답:** 상태 갱신과 화면 표시 책임을 섞으면 결과 재현·테스트가 어려워집니다. 갱신 단계로 모으는 편이 명확합니다.
