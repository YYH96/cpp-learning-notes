## 배운 내용
C++ 소스를 컴파일하면 목적 파일이 만들어지고, 링커가 여러 목적 파일과 라이브러리를 연결해 실행 파일을 만듭니다. 실행 중인 프로그램을 프로세스라고 부릅니다. 콘솔 예제에서는 main 함수가 시작점이며, include는 필요한 선언을 가져오고 주석은 사람이 읽는 설명입니다.
**Visual Studio에서 확인한 도구:** F5 실행·계속, Ctrl+F5 디버깅 없이 실행, F9 중단점, F10 한 단계씩 실행하며 함수 내부는 건너뛰기, F11 함수 내부 진입, Shift+F11 현재 함수 빠져나오기, F12 정의로 이동.
SVN에서는 checkout으로 작업 사본을 만들고, update로 서버 변경을 받고, add로 파일을 등록한 뒤 commit으로 올립니다. revert는 로컬 수정을 되돌리는 동작입니다.
## 가장 작은 프로그램

```cpp
#include <iostream>
int main() {
    // 한 줄 주석
    std::cout << "Hello World!\n";
    return 0;
}
```

📎 [실행할 예제 파일](../examples/01_hello.cpp)

**확인할 것:** 문자열은 큰따옴표, 문자는 작은따옴표입니다. 세미콜론은 문장의 끝이며 중괄호는 코드 블록입니다.
