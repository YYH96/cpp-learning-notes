# 선언과 정의

## 개념과 동작 원리

선언은 이름과 타입의 사용 계약을 알리고, 정의는 함수 본문이나 객체를 제공합니다. 컴파일러는 호출 방법을 검사할 선언이 필요하고, 실제 호출에는 대응하는 구현이 필요합니다.

## 사용 시점과 다른 개념의 구분

헤더에 함수 선언을 공유하고 소스에 구현을 둘 때 구분합니다. 일반 비-inline 함수의 정의를 여러 소스에서 중복 제공하면 링크 문제가 생길 수 있습니다.

## 문법과 예제

| 구분 | 하는 일 | 예 |
| --- | --- | --- |
| 선언 | 이름·타입·사용 방법을 알림 | int Add(int a, int b); |
| 정의 | 실제 구현이나 객체를 제공 | int Add(int a, int b) { return a + b; } |
| 호출 | 정의된 동작을 실행 | Add(2, 3); |

**주의:** 함수 선언만 있고 정의가 없으면, 그 함수를 호출하는 프로그램은 링크 오류가 날 수 있습니다.

## 예제를 이해하는 순서

int Add(int, int);만 있으면 호출의 타입은 검사할 수 있습니다. 본문이 없는 상태로 실제 호출을 연결하려 하면 구현을 찾지 못할 수 있습니다.

## 먼저 선언하고 나중에 정의하기

```cpp
#include <iostream>
int Add(int a, int b); // 선언
int main() {
    std::cout << Add(2, 3);
}
int Add(int a, int b) { // 정의
    return a + b;
}
```

**결과:** 5. main보다 본문이 아래에 있어도 앞의 선언으로 호출 방법을 확인할 수 있습니다. 마지막 정의를 제거하면 실제 호출을 연결할 구현이 없어집니다.

## 이해 확인

**질문:** 모든 선언이 저장 공간을 만드는가?

**답:** 아닙니다. 함수 선언이나 extern 변수 선언처럼 사용 방법만 알리는 선언도 있습니다.
