# 대입·복합 대입 연산자

오른쪽 값을 왼쪽 변수에 저장하거나 기존 값을 갱신합니다.

## 개념과 동작 원리

대입은 수정 가능한 왼쪽 객체에 오른쪽 결과를 저장합니다. 복합 대입은 기존 값에 연산을 적용하고 같은 대상에 결과를 반영합니다.

## 사용 시점과 다른 개념의 구분

점수 누적·체력 차감·플래그 갱신처럼 상태를 바꿀 때 사용합니다. 식의 값만 계산하는 +와 실제로 저장하는 +=를 구분합니다.

## 문법과 예제

| 기호 | 뜻 | 풀어 쓴 의미 |
| --- | --- | --- |
| = | 저장 | x = 5 |
| +=, -= | 더하기·빼기 후 저장 | x += 2는 x = x + 2 |
| *=, /=, %= | 곱하기·나누기·나머지 후 저장 | x *= 2는 x = x * 2 |
| &=, \|=, ^= | 비트 연산 후 저장 | flags \|= mask |
| <<=, >>= | 비트 이동 후 저장 | flags <<= 1 |

```cpp
int hp = 100;
hp -= 20;
hp += 5;
std::cout << hp;
```

**결과:** 85.

**주의:** =는 대입, ==는 비교입니다. 복합 대입은 왼쪽 대상을 한 번 평가합니다. int 변수에 실수 계산 결과를 저장하면 소수 부분이 사라질 수 있습니다. a = b = 0은 b에 먼저 저장하고 a에 저장합니다.

## 예제를 이해하는 순서

hp -= 20에서 이전 100이 80으로 갱신되고, hp += 5에서 85가 됩니다. =는 같음 판단이 아니라 저장 동작입니다.

## 이해 확인

**질문:** x += y와 x = x + y는 완전히 같은가?

**답:** 단순 변수에서는 같은 결과지만 복합 대입의 왼쪽 대상은 한 번 평가됩니다.
