# reserve

vector의 최소 용량을 확보합니다. 실제 원소 수는 늘리지 않습니다.

## 개념과 동작 원리

요청한 개수 이상을 담을 용량을 확보하되 size를 바꾸지 않습니다. 재할당이 필요한 경우 기존 원소를 새 저장 공간으로 옮기거나 복사할 수 있습니다.

## 사용 시점과 다른 개념의 구분

최종 개수를 대략 알 때 반복 추가의 재할당을 줄이는 데 사용합니다. 원소를 먼저 만들고 접근하려는 목적은 resize와 구분합니다.

## 문법과 예제

```cpp
std::vector<int> values;
values.reserve(10);
std::cout << values.size() << ' ' << (values.capacity() >= 10);
```

**결과:** 0 1. 아직 values[0]에 접근하면 안 됩니다. 재할당이 발생하면 기존 포인터·참조·반복자가 무효화됩니다.

## 예제를 이해하는 순서

빈 vector에 reserve(10)을 호출하면 size는 0이고 capacity는 10 이상입니다. push_back 등으로 원소를 생성한 뒤 접근합니다.

## 이해 확인

**질문:** reserve를 매 추가마다 조금씩 호출하면 좋은가?

**답:** 성장 전략을 방해해 반복 재할당을 늘릴 수 있습니다. 한 번의 합리적인 용량 계획이 유리합니다.
