# 비교 연산자

두 값을 비교해 bool 결과를 만듭니다.

| 기호 | 의미 | 예 |
| --- | --- | --- |
| == | 같음 | 3 == 3은 true |
| != | 다름 | 3 != 4는 true |
| <, > | 작음·큼 | 3 < 4는 true |
| <=, >= | 작거나 같음·크거나 같음 | 3 >= 3은 true |

```cpp
int score = 80;
bool pass = score >= 60;
bool inRange = 0 <= score && score <= 100;
std::cout << std::boolalpha << pass << ' ' << inRange;
```

**결과:** true true.

**주의:** 0 <= score <= 100은 수학의 범위 비교처럼 동작하지 않습니다. &&로 두 비교를 연결합니다. 실수는 오차 때문에 정확한 == 비교가 부적합할 수 있습니다. C 문자열의 내용 비교는 포인터의 ==로 하지 않습니다.
