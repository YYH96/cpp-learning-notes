# this 포인터

비정적 멤버 함수에서 현재 객체를 가리킵니다. 매개변수와 멤버 이름이 같을 때 멤버를 분명히 지정할 수 있습니다.

## 개념과 동작 원리

비정적 멤버 함수는 어떤 객체에 호출되었는지에 따라 this를 갖습니다. this->member는 그 호출 대상의 멤버를 지정합니다.

## 사용 시점과 다른 개념의 구분

매개변수와 멤버 이름의 충돌 해소·자기 객체 반환 등에 사용합니다. static 함수는 특정 객체를 전제로 하지 않아 this가 없습니다.

## 문법과 예제

```cpp
class Player { // main 밖
    int hp = 100;
public:
    void SetHp(int hp) { this->hp = hp; }
    int GetHp() const { return hp; }
};
```

**예:** hero.SetHp(80)을 호출하면 그 객체의 hp가 80. static 멤버 함수에는 this가 없습니다.

## 예제를 이해하는 순서

SetHp(int hp)의 hp는 매개변수 이름입니다. this->hp는 현재 객체의 멤버이므로 두 대상을 구분해 값을 저장합니다.

## 이해 확인

**질문:** hp = hp만 쓰면 멤버가 바뀌는가?

**답:** 매개변수가 같은 이름을 가리면 자기 자신에 대입할 뿐입니다. this로 멤버를 지정해야 합니다.
