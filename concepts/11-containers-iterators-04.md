# iterator와 삭제 후 순회

begin은 첫 원소, end는 마지막 원소 다음 경계입니다. **end는 역참조하지 않습니다.**

## 개념과 동작 원리

반복자는 컨테이너의 위치를 표현하며 이동·역참조로 원소를 순회합니다. end는 마지막 원소 다음 경계이므로 원소가 있는 위치가 아닙니다.

## 사용 시점과 다른 개념의 구분

컨테이너에 독립적인 순회·찾기·삭제에 사용합니다. 반복자 무효화 규칙은 컨테이너와 연산에 따라 달라집니다.

## 문법과 예제

```cpp
std::list<int> values{1, 2, 3};
for (auto it = values.begin(); it != values.end();) {
    if (*it == 2) it = values.erase(it);
    else ++it;
}
```

**결과:** 1, 3만 남습니다. erase는 다음 반복자를 반환합니다. 삭제한 원소의 반복자를 계속 쓰면 안 됩니다.

## 예제를 이해하는 순서

2를 삭제한 뒤 erase 반환값으로 다음 위치를 받습니다. 삭제하지 않은 회차에서만 ++it을 하므로 다음 원소를 건너뛰지 않습니다.

## 이해 확인

**질문:** 삭제 후 모든 반복자가 유지되는가?

**답:** list는 삭제된 원소의 반복자가 무효화되지만 vector 삭제는 삭제 지점 이후 반복자 등이 무효화됩니다.
