# 15. 내가 설명하고 구현할 수 있어야 하는 것

> **학습 목표** · 학습 내용을 자신의 말로 설명하고 직접 구현할 수 있는지 확인한다.

- [ ] 입력을 받아 적절한 자료형에 저장하고 정수/실수 연산 차이를 설명할 수 있다.
- [ ] 조건문·반복문을 조합해 메뉴와 종료 조건을 만든다.
- [ ] 기능을 함수로 분리하고 값·포인터·참조 전달의 차이를 설명한다.
- [ ] 배열 범위를 지키고 2차원 좌표를 1차원 인덱스로 변환한다.
- [ ] 문자열 입력·수정·검색과 실패 판정을 구현한다.
- [ ] 객체의 데이터를 보호하고 생성자·소멸자로 시작·끝을 관리한다.
- [ ] 상속·가상 함수·추상 클래스가 어떤 호출을 만드는지 설명한다.
- [ ] vector의 size/capacity와 list의 반복자·삽입/삭제 규칙을 설명한다.
- [ ] 직접 만든 가변 배열과 양방향 리스트의 포인터 변경을 따라갈 수 있다.
- [ ] 게임의 입력·갱신·출력·종료와 씬 전환을 역할별로 분리한다.
