# 산술 연산자

값을 더하고 빼거나, 곱셈·나눗셈·나머지를 계산합니다.

## 개념과 동작 원리

산술 연산자는 피연산자의 값을 이용해 새 계산 결과를 만듭니다. 혼합 타입 계산에는 타입 변환이 적용될 수 있고, 결과의 타입과 범위를 함께 확인해야 합니다.

## 사용 시점과 다른 개념의 구분

합계·체력 감소·좌표 이동은 덧셈과 뺄셈, 주기 판단과 짝수 검사는 나머지 연산을 사용합니다. %는 실수 나머지 함수와 구분합니다.

## 문법과 예제

| 기호 | 의미 | 예와 결과 |
| --- | --- | --- |
| + | 덧셈 / 단항 양수 | 7 + 3 = 10, +7 = 7 |
| - | 뺄셈 / 부호 반전 | 7 - 3 = 4, -7 |
| * | 곱셈 | 7 * 3 = 21 |
| / | 나눗셈 | 7 / 3 = 2, 7.0 / 2 = 3.5 |
| % | 정수 나머지 | 7 % 3 = 1 |

```cpp
int a = 7, b = 3;
std::cout << a + b << ' ' << a - b << ' ' << a * b << ' '
          << a / b << ' ' << a % b;
```

**결과:** 10 4 21 2 1.

**주의:** 정수끼리 /는 소수 부분을 버립니다. 실수 결과는 나누기 전에 실수로 변환합니다. %는 정수에 사용하고, 정수 /와 %에서 분모 0은 금지입니다. 부호 있는 정수의 표현 범위를 넘는 계산도 피합니다.

## 예제를 이해하는 순서

a와 b가 int여서 a / b는 정수 나눗셈입니다. 변수 자체는 별도 대입이 없는 한 바뀌지 않고, 계산 결과만 출력됩니다.

## 이해 확인

**질문:** a + b를 쓰면 a가 변경되는가?

**답:** 아닙니다. 결과를 a에 반영하려면 a = a + b 또는 a += b 같은 갱신이 필요합니다.
