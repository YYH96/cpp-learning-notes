# 정수 나눗셈과 형변환

## 개념과 동작 원리

산술식의 피연산자 타입이 계산 방식에 영향을 줍니다. 정수끼리 나누면 소수 부분을 버린 정수 결과가 만들어집니다.

## 사용 시점과 다른 개념의 구분

평균·비율은 나누기 전에 한 피연산자를 실수로 변환합니다. 계산이 끝난 뒤 결과를 실수 변수에 담아도 버린 소수 부분은 돌아오지 않습니다.

## 문법과 예제

```cpp
int total = 5;
double wrong = total / 2;
double correct = static_cast<double>(total) / 2;
```

**결과:** wrong은 2.0, correct는 2.5. 계산이 끝난 뒤 double에 저장해도 이미 버린 소수 부분은 복구되지 않습니다.

## 예제를 이해하는 순서

7 / 2는 3이고 static_cast<double>(7) / 2는 3.5입니다. double average = 7 / 2;도 계산 자체는 정수 나눗셈입니다.

## 이해 확인

**질문:** 변환은 언제 해야 하는가?

**답:** 필요한 계산이 수행되기 전에 해야 합니다. 저장할 변수의 타입만 바꾸는 것으로 충분하지 않을 수 있습니다.
