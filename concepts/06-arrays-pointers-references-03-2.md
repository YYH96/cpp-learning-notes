# 값·포인터·참조 전달

T는 값 복사, T*는 주소 전달, T&는 참조 전달입니다. 원본을 읽기만 하는 큰 객체는 const T&를 고려합니다.

## 개념과 동작 원리

값 매개변수는 별도 객체로 초기화되고, 포인터 매개변수는 주소값을 받아 대상을 간접 접근하며, 참조 매개변수는 원본에 바인딩됩니다.

## 사용 시점과 다른 개념의 구분

작은 단순 값은 값 전달, 수정해야 하는 원본은 참조 등을 사용합니다. 선택적 대상이나 주소 교체를 표현할 필요가 있으면 포인터 인터페이스를 고려합니다.

## 문법과 예제

```cpp
void ByValue(int x) { x = 0; } // main 밖
void ByPointer(int* x) { if (x) *x = 0; }
void ByReference(int& x) { x = 0; }
```

**예:** int hp = 100; 뒤 ByValue(hp)는 원본 유지, ByPointer(&hp)와 ByReference(hp)는 hp를 0으로 바꿉니다. 참조 전달은 유효한 객체에 바인딩해야 합니다.

## 예제를 이해하는 순서

ByValue는 지역 복사본만 바꾸고, ByPointer와 ByReference는 원본 값을 바꿉니다. 포인터 자체는 값으로 전달되므로 함수 안에서 주소만 바꾸면 호출자의 포인터는 그대로입니다.

## 이해 확인

**질문:** const T&는 무엇을 보장하는가?

**답:** 그 참조를 통해 대상을 변경하지 못하게 제한합니다. 다른 경로의 변경 가능성까지 항상 없애는 것은 아닙니다.
