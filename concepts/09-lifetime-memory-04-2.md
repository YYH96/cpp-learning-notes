# 복사 대입

이미 존재하는 객체에 다른 객체의 값을 복사합니다. 새 객체를 만드는 복사 생성과 구분합니다.

## 개념과 동작 원리

이미 존재하는 대상 객체를 다른 객체의 값으로 갱신하는 연산입니다. 대상에 기존 자원이 있을 수 있어 복사 생성보다 정리·교체 책임을 추가로 고려합니다.

## 사용 시점과 다른 개념의 구분

기존 플레이어 상태·문자열을 새 값으로 교체할 때 사용합니다. T b = a는 초기화, b = a는 대입이라는 생명주기 차이를 봅니다.

## 문법과 예제

```cpp
std::string a = "Hero", b = "Mage";
b = a;
std::cout << b;
```

**결과:** Hero. 자원 소유 클래스는 기존 자원 정리와 자기 대입도 고려해야 합니다.

## 예제를 이해하는 순서

Mage 내용을 가진 b에 a의 Hero를 대입해 b의 값을 교체합니다. string은 기존 자원 관리와 복사 처리를 제공하므로 사용자는 직접 해제하지 않습니다.

## 복사 대입 연산자의 형태

```cpp
#include <iostream>
struct State {
    int hp;
    State& operator=(const State& other) {
        hp = other.hp;
        return *this;
    }
};
int main() {
    State original{100}, target{20};
    target = original;
    std::cout << original.hp << ' ' << target.hp;
}
```

**결과:** 100 100. target은 대입 전에 이미 존재합니다. 반환하는 `*this`는 갱신한 자기 객체이며 반환형 `State&`는 그 객체의 참조입니다. int 멤버만 있는 경우 기본 대입으로도 처리할 수 있습니다.

## 이해 확인

**질문:** 자기 자신에 대입하면 자원 소유 클래스가 항상 안전한가?

**답:** 사용자 정의 구현이 기존 자원을 먼저 지우면 문제가 생길 수 있어 자기 대입·예외 안전성을 고려합니다.
