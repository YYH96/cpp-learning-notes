# 직접 구현한 자료구조

## 개념과 동작 원리

자료구조의 내부 구현은 데이터 배치·크기 정보·연결 관계·수명 관리의 불변식을 유지하는 작업입니다. 원소 접근 기능만 구현하는 것으로 충분하지 않습니다.

## 사용 시점과 다른 개념의 구분

IntVector는 size가 capacity를 넘지 않아야 하고, 연결 리스트는 이웃의 이전·다음 관계가 일치해야 합니다. 공개 연산마다 이 규칙을 보존합니다.

## 문법과 예제

- **IntVector:** 배열 포인터·size·capacity 관리. 공간 부족 시 새 배열로 복사하고 기존 배열 해제.
- **양방향 리스트:** 데이터·이전·다음 포인터를 가진 노드. 삽입·삭제 시 이웃 연결 변경.
- **직접 만든 반복자:** 노드 포인터와 이동·역참조 연산 구현.

**구분:** 표준 vector·list의 사용법과 학습용 자료구조의 내부 구현은 별개입니다. 긴 구현 해설은 아래 응용 영역에 둡니다.

## 예제를 이해하는 순서

배열 확장에서는 새 공간 준비·원소 이전·기존 공간 정리·정보 갱신을 일관되게 처리합니다. 노드 삭제에서는 양쪽 연결 변경과 해당 노드 정리가 모두 필요합니다.

## 이해 확인

**질문:** 정상 입력 한 번만 확인하면 되는가?

**답:** 빈 구조·한 원소·처음과 끝 삭제·확장·복사·소멸도 검사해야 내부 규칙이 유지되는지 알 수 있습니다.
