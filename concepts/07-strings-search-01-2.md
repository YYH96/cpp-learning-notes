# std::string

<string>에서 제공하는 가변 길이 문자열입니다. 길이와 저장 공간을 관리하고 연결·검색 등의 함수를 제공합니다.

## 개념과 동작 원리

string은 문자 시퀀스와 길이·저장 공간을 관리하는 객체입니다. 길이를 따로 관리하므로 내부의 널 문자도 저장된 원소로 포함할 수 있습니다.

## 사용 시점과 다른 개념의 구분

입력·이름·로그 등 일반 문자열 작업에 사용합니다. 객체 자체 크기, 저장된 문자 수, 화면에 보이는 글자 수를 구분합니다.

## 문법과 예제

```cpp
std::string name = "Hero";
name += "!";
std::cout << name << ' ' << name.size();
```

**결과:** Hero! 5. [] 접근 전 인덱스를 확인하고, c_str()이 반환한 주소는 문자열 변경 후 무효화될 수 있습니다.

## 예제를 이해하는 순서

name += !는 내용을 늘려 Hero!를 만들고 size는 5가 됩니다. 이 과정에서 저장 공간이 바뀌면 이전에 얻은 주소가 무효화될 수 있습니다.

## 이해 확인

**질문:** size가 화면 글자 수와 항상 같은가?

**답:** 아닙니다. string은 char 원소 수를 세므로 UTF-8 다중 바이트 문자와 화면 글자 수가 다를 수 있습니다.
