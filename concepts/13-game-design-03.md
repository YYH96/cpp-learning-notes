# 씬 전환과 다형성

기존 씬 Exit, 현재 씬 변경, 새 씬 Enter 순서로 전환합니다. 여러 씬은 공통 Update·Draw 인터페이스로 실행합니다.

## 개념과 동작 원리

씬은 화면별 상태와 행동을 관리하는 단위입니다. 공통 인터페이스로 실행하되 전환 시 이전 씬 종료·현재 씬 변경·새 씬 진입 규칙을 정합니다.

## 사용 시점과 다른 개념의 구분

로비·게임·전투처럼 진행 단계마다 다른 행동과 화면이 있을 때 사용합니다. 씬 객체의 소유자와 종료·재사용 정책도 정합니다.

## 문법과 예제

```cpp
class Scene { // main 밖: 공통 계약
public:
    virtual ~Scene() = default;
    virtual void Update() = 0;
    virtual void Draw() = 0;
};
```

**결과:** Scene 자체는 추상 클래스. 파생 씬이 Update와 Draw를 구현해야 구체 객체를 만들 수 있습니다.

## 예제를 이해하는 순서

Scene의 Update와 Draw는 구체 씬이 구현할 계약입니다. 관리자는 공통 타입으로 현재 씬을 실행하므로 씬별 로직을 한 함수에 몰아넣지 않습니다.

## 이해 확인

**질문:** 현재 씬 메서드 실행 중 자기 씬을 바로 삭제해도 되는가?

**답:** 수명과 이후 접근을 신중히 관리해야 합니다. 전환 요청을 기록해 안전한 지점에서 적용하는 방법을 고려합니다.
