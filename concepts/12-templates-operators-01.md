# template: 타입을 매개변수로

같은 구조의 함수·클래스를 여러 타입에 적용합니다. 사용한 타입으로 필요한 코드가 컴파일 때 인스턴스화됩니다.

## 개념과 동작 원리

템플릿은 타입이나 상수 매개변수를 받아 구체적인 함수·클래스를 만드는 정의입니다. 사용한 타입에 필요한 연산이 유효해야 인스턴스화된 코드가 성립합니다.

## 사용 시점과 다른 개념의 구분

같은 알고리즘을 여러 타입에 적용할 때 사용합니다. 런타임 가상 호출과 달리 이 예제는 컴파일 시간 타입에 맞는 코드가 만들어집니다.

## 문법과 예제

```cpp
template<typename T> // main 밖
T Add(T a, T b) {
    return a + b;
}
```

```cpp
std::cout << Add<int>(2, 3); // main 안
```

**결과:** 5. Add(2, 3)처럼 타입 추론도 가능합니다. 이 함수는 해당 타입의 + 연산과 반환이 유효해야 합니다. Add(2, 3.5)는 두 인자로 같은 T를 추론할 수 없어 실패합니다.

## 예제를 이해하는 순서

Add<int>에서는 T가 int로 바뀌고 + 결과를 int로 반환합니다. Add(2, 3)은 추론 가능하지만 2와 3.5는 같은 T를 유일하게 추론하지 못합니다.

## 이해 확인

**질문:** 템플릿은 모든 타입에 자동으로 동작하는가?

**답:** 아닙니다. 해당 타입이 본문에서 요구하는 연산·변환을 지원해야 합니다.
