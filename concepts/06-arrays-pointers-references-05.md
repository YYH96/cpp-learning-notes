# 2차원 배열과 좌표

## 개념과 동작 원리

2차원 배열은 행 배열들이 연속 저장된 배열입니다. 첫 인덱스는 행, 두 번째는 열이며 두 차원의 경계를 각각 지켜야 합니다.

## 사용 시점과 다른 개념의 구분

게임 보드·격자·행렬에 사용합니다. 평탄한 저장 공간에서는 행 번호에 열 수를 곱한 뒤 열 번호를 더해 원소를 찾습니다.

## 문법과 예제

```cpp
int board[2][3] = {{10, 20, 30}, {40, 50, 60}};
std::cout << board[1][2];
```

**결과:** 60. row는 행, col은 열. 1차원으로 저장하면 인덱스는 `row * 열 수 + col`입니다.

**주의:** int board[2][3]은 int**가 아닙니다. 함수의 int arr[] 매개변수는 포인터로 조정되므로 길이를 따로 전달합니다.

## 예제를 이해하는 순서

board[1][2]는 두 번째 행의 세 번째 값 60입니다. 열 수 3인 평탄 배열에서는 같은 칸의 인덱스가 1 * 3 + 2, 즉 5입니다.

## 이해 확인

**질문:** int board[2][3]을 int**로 넘길 수 있는가?

**답:** 아닙니다. 연속된 행 배열의 구조와 포인터들의 포인터 구조는 다릅니다.
