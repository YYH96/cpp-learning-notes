# static_cast

명시적 숫자 변환 등에 사용합니다. 다운캐스팅 시 실제 객체 타입을 실행 중 검사하지 않습니다.

## 개념과 동작 원리

지원되는 타입 변환을 명시해 컴파일러가 정해진 변환 규칙을 적용하도록 합니다. 다운캐스트의 실제 객체 타입을 실행 중 검사해 주는 도구는 아닙니다.

## 사용 시점과 다른 개념의 구분

숫자 변환·열거값 정수 표현 등 의도가 분명한 변환에 사용합니다. 실행 중 타입 확인이 필요하면 dynamic_cast 등 다른 설계를 비교합니다.

## 문법과 예제

```cpp
int total = 7;
double average = static_cast<double>(total) / 2;
std::cout << average;
```

**결과:** 3.5. 나눗셈 후 변환하면 이미 버린 소수 부분은 복원되지 않습니다.

## 예제를 이해하는 순서

total을 double로 바꾼 뒤 나누므로 average가 3.5가 됩니다. 변환이 값 표현을 바꿀 수 있으므로 범위와 정밀도 손실을 확인합니다.

## 이해 확인

**질문:** 캐스트를 쓰면 손실이 없어지는가?

**답:** 아닙니다. 명시했다는 것은 의도 표시이지 원래 값의 완전한 보존 보장이 아닙니다.
