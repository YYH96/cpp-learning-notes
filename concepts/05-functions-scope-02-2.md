# 기본 인자

호출에서 인자를 생략하면 미리 지정한 값을 사용합니다. 생략할 수 있는 인자는 뒤쪽에 둡니다.

## 개념과 동작 원리

호출에서 뒤쪽 인자를 생략하면 선언에 지정된 기본 식을 사용합니다. 호출자가 전체 인자를 제공하면 기본 식 대신 제공한 인자를 사용합니다.

## 사용 시점과 다른 개념의 구분

자주 쓰는 옵션을 간단히 생략할 때 사용합니다. 기본 인자와 여러 오버로드를 함께 설계하면 호출이 모호해질 수 있습니다.

## 문법과 예제

```cpp
int Scale(int value, int factor = 2) { // main 밖
    return value * factor;
}
```

**결과:** Scale(3)은 6, Scale(3, 4)는 12. 선언과 정의에 같은 기본 인자를 중복 지정하지 않습니다.

## 예제를 이해하는 순서

Scale(3)은 factor를 2로 사용해 6을 반환합니다. Scale(3, 4)는 제공한 4를 사용해 12를 반환합니다.

## 이해 확인

**질문:** 기본 인자 값은 선언 시 항상 한 번 계산되는가?

**답:** 일반적으로 해당 인자가 생략된 호출에서 기본 인자 식을 평가합니다. 항상 상수일 필요는 없습니다.
