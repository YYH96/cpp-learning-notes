# 삼항 조건 연산자

조건 ? 참일 때 값 : 거짓일 때 값 형식으로 두 값 중 하나를 선택합니다. 조건에 따라 선택된 쪽만 평가합니다.

## 개념과 동작 원리

조건식에 따라 두 후보 중 하나의 값 또는 결과 객체를 선택하는 표현식입니다. 선택되지 않은 피연산자는 평가하지 않습니다.

## 사용 시점과 다른 개념의 구분

최댓값·표시 문구처럼 짧은 값 선택에 사용합니다. if는 실행 문장을 선택하고, 삼항 연산은 다른 식에 사용할 결과를 만듭니다.

## 문법과 예제

```cpp
int hp = 30;
std::string state = hp > 0 ? "Alive" : "Dead";
int maxValue = 7 > 3 ? 7 : 3;
std::cout << state << ' ' << maxValue;
```

**결과:** Alive 7.

**주의:** 값을 선택할 때 간결합니다. 여러 동작을 수행하거나 중첩이 깊어지면 if / else로 풀어 씁니다. 두 결과의 타입 조합에 따라 변환이 일어날 수 있습니다.

## 예제를 이해하는 순서

hp > 0이 참이어서 Alive가 선택됩니다. 결과를 state 초기화에 바로 쓸 수 있으므로 별도 분기 대입보다 간결합니다.

## 이해 확인

**질문:** 분기가 길어져도 삼항이 좋은가?

**답:** 여러 동작이나 깊은 중첩은 if로 풀어 쓰는 편이 흐름과 실수를 확인하기 쉽습니다.
