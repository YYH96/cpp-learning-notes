# 산술 연산자

값을 더하고 빼거나, 곱셈·나눗셈·나머지를 계산합니다.

| 기호 | 의미 | 예와 결과 |
| --- | --- | --- |
| + | 덧셈 / 단항 양수 | 7 + 3 = 10, +7 = 7 |
| - | 뺄셈 / 부호 반전 | 7 - 3 = 4, -7 |
| * | 곱셈 | 7 * 3 = 21 |
| / | 나눗셈 | 7 / 3 = 2, 7.0 / 2 = 3.5 |
| % | 정수 나머지 | 7 % 3 = 1 |

```cpp
int a = 7, b = 3;
std::cout << a + b << ' ' << a - b << ' ' << a * b << ' '
          << a / b << ' ' << a % b;
```

**결과:** 10 4 21 2 1.

**주의:** 정수끼리 /는 소수 부분을 버립니다. 실수 결과는 나누기 전에 실수로 변환합니다. %는 정수에 사용하고, 정수 /와 %에서 분모 0은 금지입니다. 부호 있는 정수의 표현 범위를 넘는 계산도 피합니다.
