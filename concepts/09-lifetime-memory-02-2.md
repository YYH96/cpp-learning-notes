# static 멤버

클래스의 모든 객체가 공유하는 변수와 객체 없이 호출할 수 있는 함수입니다.

## 개념과 동작 원리

정적 데이터 멤버는 특정 객체마다 복제되지 않고 클래스의 객체들이 공유합니다. 정적 멤버 함수는 특정 객체 없이 호출되며 this가 없습니다.

## 사용 시점과 다른 개념의 구분

총 생성 수·공유 설정·클래스 관련 유틸리티에 사용합니다. 객체마다 다른 hp 같은 상태는 비정적 멤버로 두는 것이 자연스럽습니다.

## 문법과 예제

```cpp
class Counter { // main 밖: C++17
public:
    inline static int count = 0;
    static void Increase() { ++count; }
};
```

**예:** Counter::Increase() 뒤 Counter::count는 1. static 멤버 함수에는 this가 없어 비정적 멤버에 바로 접근할 수 없습니다.

## 예제를 이해하는 순서

Counter::count 하나를 Increase에서 갱신합니다. C++17의 inline static 정의는 헤더에서 공유 멤버 정의를 표현하는 데 사용할 수 있습니다.

## 이해 확인

**질문:** static 함수에서 일반 멤버를 쓸 수 있는가?

**답:** 객체 없이 바로 접근할 수는 없습니다. 별도의 객체나 포인터·참조가 있어야 합니다.
