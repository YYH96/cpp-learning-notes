# 연산자 오버로딩

사용자 정의 타입의 연산 의미를 정합니다. 기존 연산자의 우선순위·피연산자 개수는 바꾸지 못합니다.

## 개념과 동작 원리

사용자 정의 타입에 기존 연산 기호의 의미를 함수로 제공하는 기능입니다. 우선순위·피연산자 수·기본 내장 타입의 연산 규칙 자체를 바꾸지는 못합니다.

## 사용 시점과 다른 개념의 구분

좌표 비교·벡터 합처럼 자연스럽고 일관된 의미에 사용합니다. 함수 오버로딩은 호출 후보 선택, 연산자 오버로딩은 기호의 타입별 의미 정의입니다.

## 문법과 예제

```cpp
struct Position { // main 밖
    int x, y;
    bool operator==(const Position& other) const {
        return x == other.x && y == other.y;
    }
};
```

```cpp
Position a{1, 2}, b{1, 2}; // main 안
std::cout << (a == b);
```

**결과:** 1. 좌표 비교처럼 자연스러운 의미를 유지합니다. 함수 오버로딩과 연산자 오버로딩도 구분합니다.

## 예제를 이해하는 순서

Position의 ==는 x와 y가 모두 같은지를 계산합니다. 함수 뒤 const는 비교하는 자기 객체를 이 멤버 함수에서 일반적으로 수정하지 않는 계약입니다.

## 이해 확인

**질문:** C++17에서 ==만 정의하면 !=도 자동 제공되는가?

**답:** 자동 제공을 가정하면 안 됩니다. 사용하는 언어 버전과 해당 연산 정의를 확인해야 합니다.
