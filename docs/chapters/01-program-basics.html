프로그램의 구조와 개발 도구

한눈에 보는 핵심

C++ 프로그램은 소스를 컴파일하고 연결한 뒤 main 함수에서 실행을 시작합니다.

01

컴파일

소스의 문법을 검사하고 목적 파일을 만듭니다.

02

링크

여러 목적 파일과 라이브러리를 실행 파일로 연결합니다.

03

디버깅

중단점과 단계 실행으로 값·호출 흐름을 확인합니다.

개념 비교

구분역할실패 시점
컴파일 오류문법·선언·타입 확인실행 파일 생성 전
링크 오류함수·변수 정의 연결목적 파일 연결 중
런타임 오류실행 중 잘못된 동작프로그램 실행 중
자주 헷갈리는 점

include는 선언을 가져오는 전처리 지시문입니다. 함수 정의가 빠지면 링크 오류가 날 수 있습니다.

상세 설명과 예제 펼치기필요한 내용만 골라 읽기+

배운 내용

C++ 소스를 컴파일하면 목적 파일이 만들어지고, 링커가 여러 목적 파일과 라이브러리를 연결해 실행 파일을 만듭니다. 실행 중인 프로그램을 프로세스라고 부릅니다. 콘솔 예제에서는 main 함수가 시작점이며, include는 필요한 선언을 가져오고 주석은 사람이 읽는 설명입니다. Visual Studio에서 확인한 도구: F5 실행·계속, Ctrl+F5 디버깅 없이 실행, F9 중단점, F10 한 단계씩 실행하며 함수 내부는 건너뛰기, F11 함수 내부 진입, Shift+F11 현재 함수 빠져나오기, F12 정의로 이동. SVN에서는 checkout으로 작업 사본을 만들고, update로 서버 변경을 받고, add로 파일을 등록한 뒤 commit으로 올립니다. revert는 로컬 수정을 되돌리는 동작입니다.
