# dynamic_cast

다형적 기반 클래스에서 파생 타입으로 안전하게 변환할 때 검사합니다. 기반 클래스에 가상 함수가 필요합니다.

## 개념과 동작 원리

다형적 기반 객체의 실제 타입 관계를 실행 중 확인해 다운캐스트 등을 수행합니다. 포인터 변환 실패는 nullptr, 참조 변환 실패는 예외로 표현합니다.

## 사용 시점과 다른 개념의 구분

공통 인터페이스로 받은 객체의 특정 파생 기능이 필요한 경우에 제한적으로 사용합니다. 가상 인터페이스만으로 해결할 수 있으면 타입 의존을 줄일 수 있습니다.

## 문법과 예제

```cpp
class Base { public: virtual ~Base() = default; }; // main 밖
class Mage : public Base {};
```

```cpp
Mage mage;
Base* base = &mage;
Mage* actual = dynamic_cast<Mage*>(base);
std::cout << (actual != nullptr);
```

**결과:** 1. 실패한 포인터 변환은 nullptr, 실패한 참조 변환은 std::bad_cast를 던집니다.

## 예제를 이해하는 순서

Base*가 실제 Mage를 가리켜 검사된 Mage*를 얻습니다. 다른 파생 객체나 기반 객체라면 포인터 결과를 먼저 확인해야 합니다.

## 이해 확인

**질문:** 기반에 가상 함수가 없는 경우 같은 검사 다운캐스트가 가능한가?

**답:** 다형적 기반을 전제로 하는 다운캐스트에는 기반의 가상 함수가 필요합니다.
