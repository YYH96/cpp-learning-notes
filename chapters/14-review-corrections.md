# 14. 복습할 때 바로잡아야 할 부분

> **학습 목표** · 수업 원문의 미완성 부분과 복습 시 주의할 규칙을 구분한다.

수업 자료는 작성 중인 예제도 포함하므로 아래 항목을 구분합니다. 이 웹사이트에는 복습용 정리 예제를 공개하며, 수업 원문은 기존 Notion 학습 노트에서 관리합니다.
- string 길이에는 공백이 포함되고, substr·replace의 두 번째 인자는 개수입니다.
- vector의 reserve와 resize는 다릅니다. clear는 capacity를 줄이지 않으며 빈 컨테이너의 pop_back은 피해야 합니다.
- 부모의 함수가 virtual이 아니면 부모 포인터를 통한 호출이 자식 함수로 자동 연결되지 않습니다.
- 동적 객체는 생성한 주체가 해제를 책임져야 합니다. 컨테이너에서 포인터를 없애는 것과 객체를 delete하는 것은 다릅니다.
- find·숫자 야구·상속 계층 실습에는 작성해야 할 부분이 남아 있습니다. 안내만 있는 파일을 완성 코드로 보지 않습니다.
- TextRPG는 씬 구조와 로비에서 게임 씬으로 넘어가는 단계이며 전투·탐색·상점 전체 구현이 완료된 상태가 아닙니다.
- 스택·큐·맵·set은 자료구조 목록으로 소개된 수준입니다. 이 노트는 실제 구현 예제가 있는 vector·list에 중심을 둡니다.
