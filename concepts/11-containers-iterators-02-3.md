# resize

vector의 실제 원소 수를 변경합니다. 늘리면 새 원소를 만들고 줄이면 뒤 원소를 제거합니다.

## 개념과 동작 원리

실제 원소 수를 지정한 크기로 변경합니다. 늘리면 원소를 생성하고 줄이면 뒤 원소들을 소멸시키며 capacity 축소를 보장하지 않습니다.

## 사용 시점과 다른 개념의 구분

보드 칸 수·출력 버퍼 원소 수를 먼저 정해야 할 때 사용합니다. 저장 공간 확보만 하는 reserve와 구분합니다.

## 문법과 예제

```cpp
std::vector<int> values;
values.resize(3, 7);
std::cout << values.size() << ' ' << values[0];
```

**결과:** 3 7. 원소 수를 줄인다고 capacity가 함께 줄어드는 것은 아닙니다.

## 예제를 이해하는 순서

resize(3, 7)은 실제 원소 3개를 값 7로 생성합니다. 이미 존재하는 앞 원소는 크기를 늘렸다고 모두 7로 덮어쓰는 것이 아닙니다.

## 이해 확인

**질문:** resize(0)이 메모리를 반드시 반납하는가?

**답:** 원소는 제거하지만 기존 capacity를 줄인다는 보장은 없습니다.
