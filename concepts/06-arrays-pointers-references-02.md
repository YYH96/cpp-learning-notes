# 포인터: 주소와 역참조

`&변수`는 주소를 구하고, `*포인터`는 그 주소의 객체에 접근합니다.

## 개념과 동작 원리

포인터 객체는 다른 객체·함수의 주소나 널 포인터 값을 담습니다. 포인터 타입은 무엇을 가리키는지 정하며 포인터의 수명과 대상의 수명은 별개입니다.

## 사용 시점과 다른 개념의 구분

선택적 대상·다른 객체 연결·동적 데이터 접근에 사용합니다. raw 포인터 하나만으로 누가 대상 자원을 해제해야 하는지는 알 수 없습니다.

## 문법과 예제

```cpp
int hp = 100;
int* pointer = &hp;
*pointer = 80;
```

**결과:** hp는 80. 포인터와 배열은 다른 타입이며, 배열 이름이 많은 식에서 첫 원소 포인터로 변환될 뿐입니다.

**주의:** nullptr뿐 아니라 이미 소멸한 객체의 주소도 역참조하면 안 됩니다. nullptr 검사만으로 모든 주소의 유효성을 보장할 수 없습니다.

## 예제를 이해하는 순서

pointer에는 hp의 주소가 저장되고 *pointer는 hp를 가리킵니다. *pointer = 80은 hp를 바꾸지만 pointer = 다른주소는 연결 대상을 바꿉니다.

## 이해 확인

**질문:** nullptr가 아니면 역참조가 안전한가?

**답:** 아닙니다. 해제·소멸된 객체나 범위 밖을 가리키는 포인터도 널이 아닐 수 있습니다.
