# do-while: 최소 한 번

본문을 먼저 실행하고 조건을 검사합니다. 끝의 세미콜론이 필요합니다.

## 개념과 동작 원리

본문을 먼저 실행한 뒤 조건을 검사합니다. 처음 상태가 종료 조건에 해당해도 첫 본문은 실행됩니다.

## 사용 시점과 다른 개념의 구분

메뉴 표시 후 선택·재시도 여부 확인처럼 최소 한 번의 작업이 필요한 흐름에 사용합니다. while과 조건 검사 시점이 다릅니다.

## 문법과 예제

```cpp
int menu = 0;
do {
    std::cout << "Menu\n";
} while (menu != 0);
```

**결과:** Menu 한 번 출력. while과 조건 검사 시점이 다릅니다.

## 예제를 이해하는 순서

menu가 처음부터 0이어도 Menu를 한 번 출력합니다. 그 뒤 menu != 0이 거짓이어서 반복을 끝냅니다.

## 이해 확인

**질문:** do-while은 왜 마지막에 세미콜론이 필요한가?

**답:** 뒤의 while 조건까지 하나의 do 문장을 구성하는 문법이기 때문입니다.
