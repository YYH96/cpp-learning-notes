# 헤더·소스 파일과 전방 선언

헤더는 선언과 필요한 정의를 공유하고, .cpp는 구현을 분리합니다. 전방 선언은 타입 이름만 먼저 알립니다.

## 개념과 동작 원리

번역 단위가 공유할 선언과 구현을 나눠 의존과 중복을 관리합니다. 전방 선언은 타입 이름을 알려 주지만 크기·멤버 구조를 모두 제공하지 않습니다.

## 사용 시점과 다른 개념의 구분

포인터·참조 선언으로 의존을 줄일 수 있지만 객체를 값으로 저장하거나 멤버를 사용하려면 완전한 정의가 필요합니다. 헤더 포함과 링크된 구현은 별개입니다.

## 문법과 예제

```cpp
class Player; // main 밖: 전방 선언
void Show(const Player& player);
```

**주의:** Player의 크기를 알아야 하거나 멤버를 사용하려면 완전한 정의가 필요합니다. 템플릿 정의는 보통 사용하는 곳에서 보이도록 헤더에 둡니다. 헤더 중복 포함은 include guard 등으로 막습니다.

## 예제를 이해하는 순서

class Player; 다음에는 참조 인자의 함수 선언이 가능합니다. Show의 구현에서 Player 멤버를 사용하려면 실제 클래스 정의를 포함해야 합니다.

## 이해 확인

**질문:** 헤더 중복 포함 방지는 중복 정의 문제를 모두 해결하는가?

**답:** 한 번역 단위의 중복 포함을 막는 것과 여러 소스에 일반 함수 정의가 생기는 문제는 구분해야 합니다.
