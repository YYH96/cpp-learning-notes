## 배열과 인덱스

배열은 같은 타입의 원소를 연속 저장합니다. 크기가 N이면 인덱스는 **0부터 N - 1**입니다.

```cpp
int scores[3] = {10, 20, 30};
std::cout << scores[0] << ' ' << scores[2];
```

**결과:** 10 30. scores[3]은 범위 밖이며 자동으로 막아주지 않습니다.

## 포인터: 주소와 역참조

`&변수`는 주소를 구하고, `*포인터`는 그 주소의 객체에 접근합니다.

```cpp
int hp = 100;
int* pointer = &hp;
*pointer = 80;
```

**결과:** hp는 80. 포인터와 배열은 다른 타입이며, 배열 이름이 많은 식에서 첫 원소 포인터로 변환될 뿐입니다.

**주의:** nullptr뿐 아니라 이미 소멸한 객체의 주소도 역참조하면 안 됩니다. nullptr 검사만으로 모든 주소의 유효성을 보장할 수 없습니다.

## 참조와 값·주소 전달

참조는 기존 객체의 별칭입니다. 초기화할 때 대상을 정하고 이후 다른 객체로 연결을 바꿀 수 없습니다.

```cpp
int hp = 100;
int& alias = hp;
alias = 70;
```

**결과:** hp도 70. 참조에 대입하는 것은 대상 객체의 값을 바꾸는 동작입니다.

| 비교 | 포인터 T* | 참조 T& |
| --- | --- | --- |
| 초기 연결 | nullptr로 초기화 가능 | 유효한 대상에 바인딩 |
| 다른 대상 지정 | 주소를 다시 대입 | 바인딩 대상 변경 불가 |
| 대상 접근 | *pointer | 참조 이름 그대로 |

**함수 전달:** T는 값 복사, T*는 주소 전달, T&는 참조 전달. 원본을 읽기만 한다면 const T&를 고려합니다.

## const 포인터

| 선언 | 이 포인터로 값 수정 | 주소 변경 |
| --- | --- | --- |
| const int* p | 불가 | 가능 |
| int* const p | 가능 | 불가 |
| const int* const p | 불가 | 불가 |

## 2차원 배열과 좌표

```cpp
int board[2][3] = {{10, 20, 30}, {40, 50, 60}};
std::cout << board[1][2];
```

**결과:** 60. row는 행, col은 열. 1차원으로 저장하면 인덱스는 `row * 열 수 + col`입니다.

**주의:** int board[2][3]은 int**가 아닙니다. 함수의 int arr[] 매개변수는 포인터로 조정되므로 길이를 따로 전달합니다.
